## 二、表达式解析

| 功能         | 做什么                       | 文件/入口                          |
| ------------ | ---------------------------- | ---------------------------------- |
| 表达式路由   | 根据类型分发到对应处理器     | `handlers/index.js`              |

支持的表达式类型及对应处理器：

| 表达式类型 | 示例 | 处理器 |
|-----------|------|--------|
| choose | `choose(...)` | `handlers/choose.js` |
| selection | `[1]选项A...[2]选项B` / `303→305` / `303,304,305` | `handlers/selection.js` |
| proficiency | `proficiency(...)` | `handlers/proficiency.js` |
| operation | `skill(2)` / `tool(1)` / `language(1)` | `handlers/operation.js` |
| basic | `basic(hp_per_lv+[N])` | `handlers/basic.js` |
| level | `level(...)` | `handlers/level.js` |
| resource | `resource(...)` | `handlers/resource.js` |
| table-map | `table-map(...)` | `handlers/table-map.js` |
| special | `special(...)` | `handlers/special.js` |
| attribute | `attribute(...)` | `handlers/attribute.js` |
| chain | `chain(...)` | `handlers/chain.js` |
| filter | `filter(...)` | `handlers/filter.js` |
| feat-require | `feat-require(...)` | `handlers/feat-require.js` |
| weapon-mastery | 武器精通特性 | `handlers/weapon-mastery.js` |

> `table-ref` 处理器已随中间表架构废除而删除。

| -------- | ------------------ | ---------------------------------------------- | ------------------------------------ |
| 0        | DLC 选择           | 资料来源扩展选择，确认后进入车卡流程           | `creation/steps/dlc.js`              |
| 1        | 选择种族           | 选种族 + 亚种                                  | `creation/steps/01-race.js`          |
| 2        | 选择职业           | 选职业 + 子职                                  | `creation/steps/03-class.js`         |
| 3        | 职业套装           | 起始职业装备套装选择                           | `creation/steps/04-class-package.js` |
| 4        | 选择背景           | 选背景，应用技能和装备                         | `creation/steps/05-background.js`    |
| 5        | 背景套装           | 起始背景装备套装选择                           | `creation/steps/06-background-package.js` |
| 6        | 生成属性           | 六维属性：掷骰/购点/标准数组                   | `creation/steps/07-ability.js`       |
| 7        | 背景加值           | 种族/背景属性加值应用                          | `creation/steps/08-bonus.js`         |
| 8        | 选择技能           | 职业技能 + 背景技能选择                        | `creation/steps/09-skill.js`         |
| 9        | 选择专长           | 专长选择（1级无专长则跳过）                    | `creation/steps/10-feat.js`          |
| 10       | 选择法术           | 戏法、法术位、准备法术（非施法者跳过）         | `creation/steps/11-spells.js`        |
| 11       | 购物商店           | 金币购买额外装备                               | `creation/steps/12-shopping.js`      |
| 12       | 特性选择总览       | 汇总所有来源特性，集中处理待选项目             | `creation/steps/13-review.js`（入口）+ `13-review-main.js` / `13-review-engine.js` / `13-review-collector.js` / `13-review-renderer.js` / `13-review-utils.js` |
| 13       | 填写详情           | 角色姓名、阵营、外貌等                         | `creation/steps/14-details.js`       |
| 14       | 角色卡             | 角色卡展示                                     | `creation/steps/15-sheet.js`（入口）+ `15-sheet-main.js` / `15-sheet-renderer.js` |
| 15       | 导出               | JSON 导出                                      | `creation/steps/16-export.js`        |

**车卡入口**：`creation/app.js`（DOMContentLoaded 初始化、数据加载、事件绑定）

**车卡页面**：`creation/character.html`（车卡流程的 HTML 壳，含步骤进度条、导航按钮、弹窗容器）

**步骤控制**：管理步骤切换、数据保存、前后导航 — `creation/flow/lifecycle.js` + `creation/flow/navigation.js`

**window 桥接**：把 flow 层函数与 currentStep 访问器挂全局 — `creation/flow/bridge.js`

**步骤路由**：`creation/flow/step-router.js` 的 switch 是唯一权威，按 1-15 分发到对应渲染函数。

**特性总览（步骤12）工作流**：
1. `collectAllSources()` — 收集7个来源（种族、亚种、职业、子职、背景、专长、背景包）
2. 逐个来源递归收集待选项目 → 写入 `character.pendingSelections`
3. 有待选项 → 渲染分组选择界面（左侧可折叠分组 + 右侧详情面板）
4. 无待选项 → 显示"所有特性已处理完毕"
