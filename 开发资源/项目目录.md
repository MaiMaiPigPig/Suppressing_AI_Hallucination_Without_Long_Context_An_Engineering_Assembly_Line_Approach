## 二、表达式解析

| 功能         | 做什么                       | 文件/入口                          |
| ------------ | ---------------------------- | ---------------------------------- |
| 表达式路由   | 根据类型分发到对应处理器     | `handlers/index.js`              |

支持的表达式类型及对应处理器：

| 表达式类型 | 示例 | 处理器 |
|-----------|------|--------|
| choose | `choose(...)` | `handlers/choose.js` |
| selection | `[1]选项A...[2]选项B` / `303→305` / `303,304,305` | `handlers/selection.js` |
| proficiency | `proficiency(...)` | `handlers/proficiency.js` |
| operation | `skill(2)` / `tool(1)` / `language(1)` | `handlers/operation.js` |
| basic | `basic(hp_per_lv+[N])` | `handlers/basic.js` |
| level | `level(...)` | `handlers/level.js` |
| resource | `resource(...)` | `handlers/resource.js` |
| table-map | `table-map(...)` | `handlers/table-map.js` |
| special | `special(...)` | `handlers/special.js` |
| attribute | `attribute(...)` | `handlers/attribute.js` |
| chain | `chain(...)` | `handlers/chain.js` |
| filter | `filter(...)` | `handlers/filter.js` |
| feat-require | `feat-require(...)` | `handlers/feat-require.js` |
| weapon-mastery | 武器精通特性 | `handlers/weapon-mastery.js` |

> `table-ref` 处理器已随中间表架构废除而删除。

## 四、车卡流程（15 步，步骤9未实装）

| 步骤编号 | 步骤名称           | 做什么                                         | 文件/入口                            |
| -------- | ------------------ | ---------------------------------------------- | ------------------------------------ |
| 1        | 选择种族           | 选种族 + 亚种                                  | `creation/steps/race.js`           |
| 2        | 选择职业           | 选职业 + 子职                                  | `creation/steps/class.js`          |
| 3        | 生成属性           | 六维属性：掷骰/购点/标准数组                   | `creation/steps/ability.js`        |
| 4        | 选择背景           | 选背景，应用技能和装备                         | `creation/steps/background.js`     |
| 5        | 选择技能           | 职业技能 + 背景技能选择                       | `creation/steps/skill.js`          |
| 6        | 选择专长           | 专长选择（1级无专长则跳过）                   | `creation/steps/feat.js`           |
| 7        | 选择法术           | 戏法、法术位、准备法术（非施法者跳过）         | `creation/steps/spells.js`         |
| 8        | 选择装备           | 起始装备套装选择                               | `creation/steps/package.js`        |
| 10       | 购物商店           | 金币购买额外装备                               | `creation/steps/shopping.js`       |
| 11       | 奖励属性           | 种族属性加值应用                               | `creation/steps/bonus.js`          |
| 12       | DLC 选择           | 资料来源扩展选择                               | `creation/steps/dlc.js`            |
| 13       | 填写详情           | 角色姓名、阵营、外貌等                         | `creation/steps/details.js`        |
| 14       | 特性选择总览       | 汇总所有来源特性，集中处理待选项目             | `creation/steps/review.js`（入口）+ `review-main.js` / `review-collector.js` |
| 15       | 角色详情           | 角色姓名、阵营、外貌等                         | `creation/steps/details.js`        |
| 16       | 角色卡             | 角色卡展示                                     | `creation/steps/sheet.js`（入口）+ `sheet-main.js` / `sheet-renderer.js` |
| 17       | 导出               | JSON/PDF 导出                                  | `creation/steps/export.js`         |
| —        | 特性选择公共模块   | 检测待选项、渲染选择页、管理 pendingSelections | `creation/steps/feature-selection.js`（入口）+ `-main.js` / `-renderer.js` / `-utils.js` |
| —        | 步骤控制           | 管理步骤切换、数据保存、前后导航               | `creation/flow/lifecycle.js` + `flow/navigation.js` |
| —        | window 桥接        | 把 flow 层函数与 currentStep 访问器挂全局      | `creation/flow/bridge.js`          |

**步骤 9**：特性额外选择，无待选项时自动跳步（不产出页面）。

**「步骤」编号说明**：`step-router.js` 的 switch 是唯一权威，1-17 依次为
种族/亚种/职业/职业套装/背景/背景套装/基础属性/背景加值/特性额外选择/技能/专长/法术/商城/特性总览/角色详情/角色卡/导出。

**特性总览（步骤14）工作流**：
1. `collectAllSources()` — 收集7个来源（种族、亚种、职业、子职、背景、专长、背景包）
2. 逐个来源递归收集待选项目 → 写入 `character.pendingSelections`
3. 有待选项 → 渲染分组选择界面（左侧可折叠分组 + 右侧详情面板）
4. 无待选项 → 显示"所有特性已处理完毕"

## 五、升级系统

> upgrade 侧仍是**传统 defer 脚本**（不是 ES Module）。数据与车卡渲染函数由 `upgrade/flow/bridge.js`
> （module）以 window getter 桥接到全局，两套 `dataCache` 已合一。

| 功能             | 做什么                              | 文件/入口                                          |
| ---------------- | ----------------------------------- | -------------------------------------------------- |
| 数据/渲染桥接    | 把 core/ 的 dataCache、character 与车卡渲染函数挂到 window | `upgrade/flow/bridge.js`                  |
| 共用状态与工具   | 升级状态、步骤定义、当前步骤、转义、属性调整值 | `upgrade/core.js`                        |
| 升级入口         | 页面初始化、加载数据、恢复 sessionStorage 角色 | `upgrade/upgrade.js`（26 行，仅初始化）  |
| 升级导航         | 进度条/指示器/按钮、前进后退跳转    | `upgrade/flow/navigation.js`                       |
| 升级步骤路由     | 按步骤号分发渲染函数                | `upgrade/flow/step-router.js`                      |
| 升级生命周期     | 导入角色、读档、等级收益准备        | `upgrade/flow/lifecycle.js`                        |
| 特性选择渲染     | 概览/特性/子职页面与待选项收集      | `upgrade/steps/feature-select.js`                  |
| 选择应用         | 渲染待选分组、写回角色数据          | `upgrade/steps/selection-apply.js`                 |
| 数值成长计算     | HP/命中/熟练等按等级成长            | `upgrade/steps/ability-update.js`                  |
| 升级角色卡       | 用升级后的法术列表渲染详情          | `upgrade/steps/sheet-update.js`                    |
| 升级导出         | 导出页、JSON/PDF、可打印 HTML       | `upgrade/steps/export-update.js`                   |
| 法术更新·渲染    | 已知/准备/法术书三分区渲染          | `upgrade/steps/spell-update.js`                    |
| 法术更新·交互    | 法术勾选、替换、法术书增删          | `upgrade/steps/spell-update-interactions.js`       |
| 等级选择         | 选择目标等级                        | `upgrade/steps/level-select.js`                    |
| 升级完成         | 升级流程完成确认                    | `upgrade/steps/complete.js`                        |

> ⚠️ `level-select.js` 与 `flow/lifecycle.js`、`steps/feature-select.js`、`steps/ability-update.js`
> 重复声明 6 个同名函数，靠 `upgrade.html` 的加载顺序决定生效版本（与原 `upgrade.js` 最后加载等价）。
> 改动加载顺序前务必先读 `upgrade.html` 里的顺序说明。
