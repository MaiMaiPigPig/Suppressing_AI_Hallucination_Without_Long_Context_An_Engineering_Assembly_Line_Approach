# DND 5R 车卡 & 升级规则说明

## 一、DND 5E 基础规则

### 1.1 核心概念
- **D20 检定**：所有判定基于 d20 骰子 + 修正值 vs 目标难度（DC）或对方护甲（AC）
- **优势/劣势**：优势 = 2 颗骰子取高，劣势 = 2 颗骰子取低
- **属性值**：6 大属性（力量/敏捷/体质/智力/感知/魅力），范围 3~18（标准），修正值 = (属性值-10)/2 向下取整

### 1.2 熟练加值（Proficiency Bonus）
熟练加值随角色总等级增长，适用于熟练的武器/技能/豁免：
| 角色等级 | 熟练加值 |
|---------|---------|
| 1~4 级 | +2 |
| 5~8 级 | +3 |
| 9~12 级 | +4 |
| 13~16 级 | +5 |
| 17~20 级 | +6 |

## 二、角色创建流程

### 2.1 标准建卡步骤
1. **选择种族** → 提供属性加值、种族特性、语言、速度
2. **选择职业** → 决定生命骰、熟练项、职业特性
3. **分配属性** → 标准数组/购点/骰点，6 大属性分配
4. **选择背景** → 提供技能熟练、工具熟练、背景特性、起始装备
5. **选择专长**（可选规则）→ 1 级专长（如房规允许）
6. **选择法术** → 施法职业选择初始法术/戏法
7. **购置装备** → 用起始资金购买装备
8. **填写角色卡** → 计算 AC、被动察觉、攻击加值等

## 三、升级规则

### 3.1 每次升级固定获得
| 项目 | 计算方式 |
|------|---------|
| **生命值上限** | 职业生命骰平均值 + 体质调整值 |
| **生命骰池** | 增加 1 颗对应职业的生命骰 |
| **总生命骰** | 角色等级 = 总生命骰数量 |

各职业升级生命值：
- d6 职业（法师/术士）：每级 +4 + 体质调整
- d8 职业（牧师/德鲁伊/游荡者/武僧/诗人/邪术师/吟游诗人）：每级 +5 + 体质调整
- d10 职业（战士/圣武士/游侠）：每级 +6 + 体质调整
- d12 职业（野蛮人）：每级 +7 + 体质调整

### 3.2 按等级获得的特殊内容

#### 熟练加值变化
角色总等级到达 5/9/13/17 级时，熟练加值 +1。

#### 专长 / 属性值提升（ASI）
升到特定等级时甚得一次属性提升或专长：
- **大部分职业**：4/8/12/16/19 级
- **战士额外**：6/14 级
- **游荡者额外**：10 级

每次 ASI 可以选择：
- 一项属性 +2
- 两项属性各 +1
- 选择一个专长（占用 ASI 机会）

#### 职业特性
每个职业有职业特性表（class_features.json），按等级获得新特性。
- `level` 字段 = 获得该特性的等级
- `chain` 字段 = 嵌入的子规则（如 link(id)、filter 表达式等）
- `subclass` 字段 = 非 0 时表示该特性属于某个子职业
- `code` 字段 = 特殊代码处理（如 `choose`、`spell_level` 等）

#### 子职业特性
子职业在特定等级提供额外特性，通常节奏：
- 大部分职业：3/6/10/14 级
- 牧师：1/2/6/8/17 级（取决于领域）
- 法师：2/6/10/14 级
- 邪术师：1/6/10/14 级

#### 法术位变化
施法职业按职业等级获得新的法术环位，数据存储在 proficiency.json：
- 全施法者：每级都有法术位增长
- 半施法者（圣武士/游侠）：偶数级增长
- 三分之一施法者：特定等级增长

#### 戏法（戏法）
- 施法职业在特定等级获得更多已知戏法
- 戏法伤害在角色总等级 5/11/17 级时自动增强（非 5R 特有，标准规则）

#### 职业额外资源
某些职业有可用次数/骰子等资源随等级变化（数据在 proficiency.json 的 class_extra 列）：
- 野蛮人：狂暴次数、狂暴伤害
- 诗人：诗人激励骰（d6→d8→d10→d12）
- 德鲁伊：荒野形态次数、CR 限制
- 武僧：气点、武艺骰
- 圣武士：圣疗总量、至圣斩伤害
- 游荡者：偷袭伤害骰
- 术士：术法点
- 此外还有 class_extra.json 管理的可选项（战技、魔能祈唤、超魔法等）

#### 属性调整
当属性值因 ASI 或其他效果改变时，以下项目需要重新计算：
- 属性修正值（用于技能/攻击/豁免）
- 法术豁免 DC（8 + 熟练加值 + 施法属性修正）
- 法术攻击加值（熟练加值 + 施法属性修正）
- 生命值上限（体质调整值变化时需要重新计算所有等级）
- AC（敏捷调整值变化时）

## 四、升级流程设计

### 4.1 标准升级流程
```
1. 导入已有角色 JSON 存档
   ↓
2. 选择目标等级（如从 3 级升到 7 级）
   ↓
3. 计算新旧等级之间的差距
   ↓
4. 逐级处理变化（从 3→4, 4→5, 5→6, 6→7）
   ↓
5. 每级变化中，按顺序应用：
   a. 生命值 + 生命骰
   b. 熟练加值变化（如有）
   c. 新职业特性（含子职特性）
   d. 职业额外资源变化
   e. 法术位变化
   f. 戏法变化
   g. 专长/ASI（如有）
   h. 属性变化导致的连锁调整
   ↓
6. 展示升级总览 → 确认 → 保存
```

### 4.2 等级跳跃处理
- 允许一次选择目标等级，系统自动逐级计算
- 每级可能出现需要用户选择的内容（如 ASI 选属性还是专长、选新法术等）
- 将所有需要用户选择的内容收集后，逐项让用户确认

### 4.3 增量选择原则
升级不是重新建卡，而是"只选新增的"：
- 1 级选了 2 个戏法，4 级多了 1 个戏法 → 只需要再选 1 个
- 战斗风格 1 级已选，升级不需要重新选
- ASI 每次独立选择，不覆盖之前的选择

## 五、兼职规则（后续扩展）

### 5.1 兼职核心规则
- 属性前置要求：力量 13 或敏捷 13（取决于兼职职业）
- 多职业生命骰：各职业分别计算
- 熟练项：只获得兼职职业的部分熟练项（不是全部）
- 特性：只获得兼职等级对应的特性
- 法术位：按各职业施法等级叠加计算（多职业施法者规则）
- 戏法：各职业分别计算
- 专长/ASI：按角色总等级计算

### 5.2 数据影响
- 角色有多个职业等级（如 战士 5 / 法师 2）
- 需要记录每个职业的等级
- 总等级 = 各职业等级之和
- 熟练加值看总等级
- 各职业特性分别按各自的等级获得

## 六、数据文件对照

### 6.1 核心数据文件
| JSON 文件 | 内容 | 升级用途 |
|-----------|------|---------|
| classes.json | 职业定义（hp_per_level、feat_level、subclass_level） | 生命值、专长等级、子职等级 |
| class_features.json | 职业/子职特性（level、chain、subclass、code） | 按等级筛选新特性 |
| proficiency.json | 熟练加值、法术位、职业资源 | 每级数值变化 |
| spellcasting.json | 施法属性、准备数量公式 | 法术准备量计算 |
| class_extra.json | 可选额外资源（战技、祈唤等） | 升级时的新选择 |
| spells.json | 法术数据 | 新环阶选法术 |
| lookup_table.json | 引用中间表（link 跳转） | 规则解析路由 |
| backgrounds.json | 背景数据 | 升级不改背景 |

### 6.2 规则引擎
| 模块 | 用途 |
|------|------|
| handlers/link.js | 解析 link(id)，查 lookup_table 路由 |
| handlers/filter.js | 按条件筛选数据（class=4,lv=0 等） |
| handlers/choose.js | 特殊选择操作 |
| handlers/table-ref.js | 直接引用表数据 |
| code-handlers/ | code 列特殊处理（choose/spell_level 等） |
| feature-selection.js | 待选队列 UI（升级时复用于新特性选择） |

## 七、5R 版本说明

本工具使用的 **DND 5R** 是建立在 DND 5E 基础上的变体规则（Homebrew），主要在以下方面有差异：
1. 数据表结构自定义（CSV 转 JSON，字段映射在 spell_field_mapping.json）
2. 特性规则使用自研规则表达式（link/filter/choose 体系）
3. 角色数据结构按照实际需要调整
4. 标准 5E 规则作为参考基准，实际以 JSON 数据文件为准
