## 1. utils/html.js

### 用途
把玩家输入的文本安全插入 `innerHTML`，防止 XSS。

### 导出函数

#### `escapeHtml(text)`
| 项目 | 说明 |
|------|------|
| 输入 | `text: any`（字符串/数字/null/undefined） |
| 输出 | `string` |
| 行为 | 替换 `&` `<` `>` `"` `'` 为 HTML 实体 |
| 边界 | `null`/`undefined`/`0`/`false`/`''` → `''`；数字先转 `String(text)` |

**源码位置**：`TableChronicle/character/dnd_5r/utils/html.js` L16-L22

```
export function escapeHtml(text) {
    if (!text) return '';
    return String(text)
        .replace(/&/g, '&amp;')
        .replace(/</g, '&lt;')
        .replace(/>/g, '&gt;')
        .replace(/"/g, '&quot;')
        .replace(/'/g, '&#039;');
}
```

## 2. utils/currency.js

### 用途
D&D 货币换算和格式化。

### 导出函数

#### `parsePrice(str)`
| 项目 | 说明 |
|------|------|
| 输入 | `str: string|null`，如 `"5GP"`、`"2.5 PP"`、`"10金币"` |
| 输出 | `{ value: number, unit: string }` |
| 行为 | 正则 `/[\d.]+\s*(PP|GP|EP|SP|CP|铂金币|金币|银金币|银币|铜币)?/i` 解析数值和单位 |
| 边界 | `null`/`'null'`/`'0'` → `{value:0, unit:'GP'}`；无单位 → 默认 GP |

#### `toCP(price)`
| 项目 | 说明 |
|------|------|
| 输入 | `price: string`，如 `"2GP 5SP"`（取第一组） |
| 输出 | `number`，铜币值 |
| 行为 | 内部调 `parsePrice`，乘汇率 `{PP:1000, GP:100, EP:50, SP:10, CP:1}`，`Math.round` 取整 |

#### `formatCurrency(cp)`
| 项目 | 说明 |
|------|------|
| 输入 | `cp: number`，铜币值 |
| 输出 | `string`，如 `"1PP 2GP 3SP 4CP"` |
| 行为 | 从 PP(1000) → GP(100) → EP(50) → SP(10) → CP(1) 逐级整除取余，非零才拼接 |
| 边界 | `0` → `"0GP"`；`150` → `"1GP 1EP"`（50 进位为 EP） |

**源码位置**：`TableChronicle/character/dnd_5r/utils/currency.js` L2-L37

## 6. core/data/loader.js

### 用途
数据加载、占位符预处理、翻译。

### 导出函数

#### `replacePlaceholdersInText(text, item)`
| 项目 | 说明 |
|------|------|
| 输入 | `text: string|null`，含占位符的文本；`item: Object`，含 `rules`/`dice`/`damage_type` 字段 |
| 输出 | `string` |

**占位符替换规则**：

| 占位符 | 数据来源 | 说明 |
|--------|---------|------|
| `%x%` | `item.rules` 或 `item.dice` | 取第一个值 |
| `%xN%` | 同上 | 按逗号索引（第 N 个） |
| `%y%` | `item.damage_type` | 翻译后取第一个值 |
| `%yN%` | 同上 | 按逗号索引，再展开 `/`（第 N 个） |

**yValues 翻译规则**（`translateYValue`）：

| 输入格式 | 输出格式 | 示例 |
|---------|---------|------|
| 普通值 | `translateDamageType` | `cold` → `寒冷` |
| `/` 分隔 | 逐段翻译，`/` 连接 | `psychic/penalty` → `心灵/减值` |
| `choose_` 前缀 | 去前缀，`_` 换 `/` | `choose_acid_cold` → `强酸/寒冷` |

**效果关键词映射**（`EFFECT_KEYWORD_MAP`）：
`penalty`→`减值` / `temporary_hp`→`临时生命` / `bonus`→`加值` / `healing`→`治疗`

**边界**：
- `text` 为 `null`/`undefined` → `''`
- `xValues` 和 `yValues` 均为空 → 返回原文
- `%yN%` 索引超出 → 保留 `%yN%` 原文

### 内部函数（不导出，但可通过间接路径测试）

#### `preprocessAllPlaceholders()`
遍历 `dataCache.spells`、`.races`、`.raceFeatures`、`.classFeatures` 的 `desc`/`upcast` 字段，调用 `replacePlaceholdersInText` 替换。

#### `loadData(dlcList)`
加载所有 JSON 文件 → `initDictionaryMaps` → `preprocessAllPlaceholders` → `buildDataIndexes`。

**源码位置**：`TableChronicle/character/dnd_5r/core/data/loader.js`

## 8. handlers/choose.js

### 用途

### 导出函数

#### `splitArgs(str)`
| 项目 | 说明 |
|------|------|
| 输入 | `str: string`，如 `"skill,tool(type=66)"` |
| 输出 | `string[]`，如 `["skill", "tool(type=66)"]` |

| 边界 | `""` → `[]`；单参数 `"skill"` → `["skill"]`；trim 前后空格 |

#### `parseCategory(arg)`
| 项目 | 说明 |
|------|------|
| 输入 | `arg: string`，如 `"skill"`、`"tool(type=66)"`、`"spell(class=4,lv=0)"` |
| 输出 | `Object|null`，含 `{ category, type, jsonFile, ... }` |
| 边界 | 未识别 → `null`；大小写不敏感 |

| 输入 | category | 关键字段 |
|------|----------|---------|
| `"skill"` | `'skills'` | `type:'all'` |

| `"spell(class=4,lv=0)"` | `'spells'` | `classId: 4, level: 0` |

| `"armor(type=1)"` | `'armors'` | `typeId: 1` |
| `"feats(type=42)"` | `'feats'` | `typeId: 42` |

| 项目 | 说明 |
|------|------|

| 边界 | 括号不匹配 → `success:false, message:'括号不匹配'`；缺总数 → `message:'缺少总数'`；无识别类别 → `message:'没有可识别的类别'` |

## 10. handlers/index.js

### 用途
规则解析统一入口，根据规则字符串前缀路由到对应的子模块。

### 导出

#### `handlerRegistry`
`Record<string, Module>`，子模块注册表。

#### `parseRule(rule)`

| 项目 | 说明 |
|------|------|
| 输入 | `rule: string` |
| 输出 | 各子模块 `parse()` 的返回值，或 `null` |

**路由规则**（按优先级）：

| 匹配条件 | 子模块 | 输出 type |
|---------|--------|----------|
| `prerequisite(...)` | 递归 `parseRule`（提取内容） | 不定 |
| `code(...)` / `code（...）` | 直接返回 | `'code'` |
| `all(xxx)` | 直接返回 | `'all'` |
| `half-prof(xxx)` | 直接返回 | `'special'` |
| `choose(...)+N` | choose | `'choose'` |
| `hp\|hp_per_lv\|ac=\|ac+\|speed+\|character(\|ability(N)` | basic | `'basic'` |
| `abilitymodifiers(` | attribute | `'attribute'` |
| `lv:` | level | `'level'` |
| `skill+\|工具+\|language+\|...` | proficiency | `'proficiency'` |
| `spell(\|tool(\|weapon(\|feats(` | filter | `'filter'` |
| 其他未匹配 | 直接返回 | `'unknown'` |

**复数归一化**：`spells(`→`spell(` / `tools(`→`tool(` / `weapons(`→`weapon(` / `skills(`→`skill(` / `armors(`→`armor(` / `languages(`→`language(` / `feats(`→`feat(`

**边界**：`""` → `null`；`null`/非字符串 → `String(rule)` 后返回 `null`

**源码位置**：`TableChronicle/character/dnd_5r/handlers/index.js`
