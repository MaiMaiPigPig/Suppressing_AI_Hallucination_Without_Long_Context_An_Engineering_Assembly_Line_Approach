## 任务描述

为 `handlers/basic.js`、`handlers/choose.js`、`handlers/filter.js`、`handlers/index.js` 编写单元测试，验证"规则字符串 → 结构化对象"的解析正确性。

## 测试范围

### `handlers/basic.js` — `parse(rule)`

| 用例 | 输入 | 预期输出字段 |
|------|------|-------------|
| `hp` | `'hp'` | `type:'basic'`, `subtype:'hp'`, `success:true` |
| `hp_per_lv` | `'hp_per_lv+2'` | `subtype:'hp_per_lv'`, `value:2` |
| `ac` 公式 | `'ac=10+AbilityModifiers(4)'` | `subtype:'ac'`, `formula:'10+AbilityModifiers(4)'` |
| `ac` 加值 | `'ac+2'` | `subtype:'ac_bonus'`, `value:2` |
| `speed` | `'speed+10'` | `subtype:'speed'`, `value:10` |
| `ability` 加成 | `'ability(1)+2'` | `subtype:'ability_bonus'`, `abilityId:1`, `value:2` |
| `ability` 减值 | `'ability(4)-1'` | `abilityId:4`, `value:-1` |
| `character(直接显示)` | `'character(直接显示)'` | `subtype:'display'`, `success:true` |
| 未匹配 | `'unknown_rule'` | `success:false` |
| 大小写不敏感 | `'HP'` | 同 `'hp'` 结果 |

### `handlers/choose.js` — `splitArgs(str)`

| 用例 | 输入 | 预期输出 |
|------|------|----------|
| 无嵌套 | `'skill,tool'` | `['skill', 'tool']` |
| 嵌套括号 | `'skill,tool(type=66)'` | `['skill', 'tool(type=66)']` |
| 多层嵌套 | `'a(b(c),d),e'` | `['a(b(c),d)', 'e']` |
| 空字符串 | `''` | `[]` |
| 单参数 | `'skill'` | `['skill']` |
| 空格trim | `' skill , tool '` | `['skill', 'tool']` |

### `handlers/index.js` — `parseRule(rule)`

| 用例 | 输入 | 预期输出字段 |
|------|------|-------------|
| 路由到 basic | `'hp'` | `type:'basic'`, `subtype:'hp'` |
| 路由到 choose | `'choose(skill)+1'` | `type:'choose'` |
| 路由到 filter | `'spell(class=4,lv=0)+2'` | `type:'filter'` |
| 复数归一化 | `'spells(class=4,lv=0)+2'` | 同 `'spell(...)'` 结果 |
| 路由到 attribute | `'abilitymodifiers(4)'` | `type:'attribute'`（或对应子模块返回） |
| 路由到 level | `'lv:1'` | `type:'level'` |
| 未识别 | `'unknown_xyz'` | `type:'unknown'`, `success:false` |
| 空字符串 | `''` | `null` |
| code 规则 | `'code(测试)'` | `type:'code'`, `tag:'测试'` |
| all 规则 | `'all(races)'` | `type:'all'`, `table:'races'` |
