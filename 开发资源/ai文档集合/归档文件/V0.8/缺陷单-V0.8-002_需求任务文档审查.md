### 缺陷 1：`formatCurrency(150)` 期望值跳过了 EP（银金币）

**任务文档**：任务 C "编写 utils 层测试用例"，`formatCurrency()` 表格中

> | 进位 | `150` | `'1GP 5SP'` |

**代码实际行为**（[currency.js:22-L27](file:///f:/跑团工具/TableChronicle/character/dnd_5r/utils/currency.js#L22-L27)）：

```js
pp = 0;         150 % 1000 = 150
gp = 1;         150 % 100  = 50
ep = 1;         50  % 50   = 0    // ← EP（银金币）= 50 CP
sp = 0;
cp = 0;
结果：'1GP 1EP'
```

货币单位序列为 PP(1000) → GP(100) → EP(50) → SP(10) → CP(1)。`'1GP 5SP'` 跳过了 EP 这一档，实际输出是 `'1GP 1EP'`。

**建议**：期望值改为 `'1GP 1EP'`，或换一个不经过 EP 的测试值如 `110` → `'1GP 1SP'`。
