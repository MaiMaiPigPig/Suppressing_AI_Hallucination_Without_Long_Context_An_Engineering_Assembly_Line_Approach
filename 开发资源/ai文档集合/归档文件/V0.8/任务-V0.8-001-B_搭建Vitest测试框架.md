在 `TableChronicle/character/dnd_5r/` 下搭建 Vitest 测试框架，配置 ESM 支持，创建测试目录结构，使 `npm test` 可一键运行。

## 验收标准

- [ ] `npm install` 后 `node_modules/.bin/vitest` 存在
- [ ] `npm test` 执行 `vitest run`，退出码 0（即使无测试用例也成功）
- [ ] `npm run test:watch` 执行 `vitest`，进入 watch 模式
- [ ] `npm test -- --coverage` 可生成覆盖率报告（需安装 `@vitest/coverage-v8`）
- [ ] 测试文件放在 `tests/` 目录下，按 `utils/`、`core/`、`handlers/` 分层
- [ ] 能正确 `import` 项目中的 ES Module（如 `import { escapeHtml } from '../utils/html.js'`）
