# 任务-V0.8-001-A_dictionary.js消除window依赖

**状态**：✅ 已完成

## 关联需求

[需求-V0.8-001_新增单元测试脚本](需求-V0.8-001_新增单元测试脚本.md)

## 任务描述

`dictionary.js` 的翻译函数依赖 `window.DAMAGE_TYPE_MAP` / `window.PROPERTY_MAP`，这两个映射表由 `15-sheet-renderer.js` 硬编码挂到 `window` 上。问题有三：

1. 测试环境没有 `window`，跑不起来（主因）
2. 映射数据跟 CSV 源头不一致（`cold` 写成了"冷冻"，武器属性 ID 6/7 错误等）
3. 展示层不应承载数据映射逻辑，架构方向反了

方案：新增 `initDictionaryMaps(cache)` 函数，由 `loader.js` 在数据加载后调用，从 `dictionary.json` / `weapon_properties.json` 动态构建 5 种映射表。展示层改为 `import` 新接口，不再往 `window` 挂数据。
