### `core/data/dictionary.js`

**`translateDamageType()`**

| 用例 | 输入 | 预期输出 |
|------|------|----------|
| 常见映射 | `'fire'` | 对应中文（如 `'火焰'`） |
| 未匹配原样返回 | `'custom'` | `'custom'` |
| 空值 | `''` | `'—'` |
| `null` | `null` | `'—'` |
| 横线 | `'—'` | `'—'` |
| 大小写不敏感 | `'FIRE'` | 同 `'fire'` 结果 |

**`translateProperties()`**

| 用例 | 输入 | 预期输出 |
|------|------|----------|
| 单属性 | `'1'` | 对应中文（如 `'轻型'`） |
| 多属性 | `'1,2'` | `'轻型、投掷'`（中文顿号分隔） |
| 带数字前缀 | `'1,2'` | 映射后拼接 |
| 空值 | `''` | `'—'` |
| `null` | `null` | `'—'` |
| 横线 | `'—'` | `'—'` |
| 数组输入 | `['1','2']` | 同字符串 `'1,2'` 结果 |

### `core/data/cache.js`

| 用例 | 操作 | 预期结果 |
|------|------|----------|
| `setDataCache` | 传入 `{ races: [{id:1}] }` | `dataCache.races` 可读取 |
| `setFullDataCache` | 传入同上 | `_fullDataCache.races` 可读取 |
| `resetCache` | 先 set 再 reset | `dataCache` 和 `_fullDataCache` 均为 `{}` |
| `applyDLCFilter` 白名单过滤 | 构造 `races` 含 `dlc: 'phb'` 和 `dlc: 'dmg'`，启用 `['phb']` | 仅保留 `phb` 项 |
| `applyDLCFilter` 无 dlc 字段保留 | 构造无 `dlc` 字段的项 | 始终保留 |
| `applyDLCFilter` 非白名单表全量 | 构造 `dictionary` 表数据 | 过滤后数据完整保留 |
| `applyDLCFilter` 空列表默认 phb | 传入 `null` 或 `[]` | 等效于 `['phb']` |

### `core/data/loader.js`

**`replacePlaceholdersInText()`**

| 用例 | 输入 | 预期输出 |
|------|------|----------|
| `%x%` 替换 | `text: '造成 %x% 伤害'`, `item: { rules: '1d6' }` | `'造成 1d6 伤害'` |
| `%x1%` / `%x2%` | `item: { rules: '1,2' }` | 分别替换为 `1` 和 `2` |
| `%y%` 替换 | `item: { damage_type: 'fire' }` | 替换为中文译文（需先调 `initDictionaryMaps`，否则保持原文） |
| `%y1%` / `%y2%` | `item: { damage_type: 'a,b' }` | 分别替换为 `a` 和 `b` |
| 无占位符 | `text: 'hello'` | `'hello'` |
| 无匹配值 | `text: '%x%'`, `item: {}` | `'%x%'` 或 `'?'`（按实现行为） |
| `null` text | `null`, `item: {}` | `''` |
