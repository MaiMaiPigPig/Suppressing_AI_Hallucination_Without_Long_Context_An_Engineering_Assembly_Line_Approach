## 测试范围

### `utils/html.js`

| 用例 | 输入 | 预期输出 |
|------|------|----------|
| 转义全部敏感字符 | `'<script>alert("xss")</script>'` | `'&lt;script&gt;alert(&quot;xss&quot;)&lt;/script&gt;'` |
| 转义单引号 | `"it's"` | `'it&#039;s'` |
| `null` 输入 | `null` | `''` |
| `undefined` 输入 | `undefined` | `''` |
| 空字符串 | `''` | `''` |
| 数字输入 | `123` | `'123'` |
| 无敏感字符 | `'hello world'` | `'hello world'` |
| 仅转义 & | `'A & B'` | `'A &amp; B'` |

### `utils/currency.js`

**`parsePrice()`**

| 用例 | 输入 | 预期输出 |
|------|------|----------|
| 标准格式 | `'5GP'` | `{ value: 5, unit: 'GP' }` |
| 空格分隔 | `'2.5 PP'` | `{ value: 2.5, unit: 'PP' }` |
| 中文单位-铂金币 | `'1铂金币'` | `{ value: 1, unit: 'PP' }` |
| 中文单位-金币 | `'10金币'` | `{ value: 10, unit: 'GP' }` |
| 中文单位-银金币 | `'2银金币'` | `{ value: 2, unit: 'EP' }` |
| 中文单位-银币 | `'5银币'` | `{ value: 5, unit: 'SP' }` |
| 中文单位-铜币 | `'20铜币'` | `{ value: 20, unit: 'CP' }` |
| `null` 输入 | `null` | `{ value: 0, unit: 'GP' }` |
| 字符串 `'null'` | `'null'` | `{ value: 0, unit: 'GP' }` |
| 字符串 `'0'` | `'0'` | `{ value: 0, unit: 'GP' }` |
| 无法匹配 | `'abc'` | `{ value: 0, unit: 'GP' }` |
| 无单位默认 GP | `'100'` | `{ value: 100, unit: 'GP' }` |

**`toCP()`**

| 用例 | 输入 | 预期输出 |
|------|------|----------|
| PP 换算 | `'1PP'` | `1000` |
| GP 换算 | `'1GP'` | `100` |
| EP 换算 | `'1EP'` | `50` |
| SP 换算 | `'1SP'` | `10` |
| CP 换算 | `'1CP'` | `1` |
| 复合换算 | `'2GP 5SP'`（取第一个） | `200`（按 `parsePrice` 行为） |
| 非法输入 | `'abc'` | `0` |

**`formatCurrency()`**

| 用例 | 输入 | 预期输出 |
|------|------|----------|
| 零值 | `0` | `'0GP'` |
| 仅 CP | `5` | `'5CP'` |
| 仅 SP | `10` | `'1SP'` |
| 仅 GP | `100` | `'1GP'` |
| 仅 PP | `1000` | `'1PP'` |
| 复合 | `1234` | `'1PP 2GP 3SP 4CP'` |
| 进位 | `150` | `'1GP 1EP'` |
| 大数 | `50000` | `'50PP'` |
