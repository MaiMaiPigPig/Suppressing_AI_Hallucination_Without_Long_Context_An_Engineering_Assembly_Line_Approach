# 任务卡-v0.4-003_代码迁移风险评估与审查

## 一、目标

在正式执行 v0.4-002 代码迁移前，由开发 AI 对现有代码进行风险评估，识别迁移过程中可能破坏功能的隐患点，输出风险清单和应对建议。

**本任务只评估，不修改代码。**

## 二、范围

- `TableChronicle/character/dnd_5r/creation/character.js` — 主文件，1256 行，承担 6 种职责
- `TableChronicle/character/dnd_5r/upgrade/upgrade.js` — 升级主文件，与车卡有大量重复逻辑
- `TableChronicle/character/dnd_5r/creation/steps/*.js` — 各步骤文件，检查与 character.js 的耦合点
- `TableChronicle/character/dnd_5r/handlers/index.js` — 规则引擎路由，检查全局依赖
- `TableChronicle/character/dnd_5r/creation/character.html` — 检查 script 加载顺序和全局变量暴露

## 三、评估维度

### 维度 1：全局变量依赖

**检查项**：
- `character.js` 定义了哪些全局变量（`var character`, `var dataCache`, `var abilityState` 等）
- 这些全局变量被哪些其他文件读取或修改
- 迁移到模块导出后，各文件的引用路径是否需要调整

**输出要求**：列出每个全局变量的"定义位置 → 消费位置"映射表

### 维度 2：函数调用链

**检查项**：
- `character.js` 中的函数被哪些步骤文件调用（如 `openSelectionModal`, `updateProgress`）
- 步骤文件中的函数是否反向调用 `character.js` 的函数（循环依赖）
- `upgrade.js` 与 `character.js` 的共用函数清单

**输出要求**：画出核心函数的调用关系图（文本形式即可）

### 维度 3：HTML script 加载顺序

**检查项**：
- `character.html` 中 `<script>` 标签的加载顺序
- 全局变量（如 `handlers`, `dataCache`）在哪个 script 中首次定义
- 迁移后模块化的加载顺序是否会影响初始化时机

**输出要求**：列出当前加载顺序，标注每个 script 的依赖关系

### 维度 4：数据流断裂风险

**检查项**：
- `character` 对象的字段在哪些步骤中被修改
- 步骤间传递数据的方式（全局变量？参数？返回值？）
- 提取 `core/state/character-state.js` 后，步骤文件是否需要改调用方式

**输出要求**：标出"步骤 A 写数据 → 步骤 B 读数据"的关键路径

### 维度 5：handlers 层耦合

**检查项**：
- `handlers.parseRule` 的调用方有哪些
- `handlers` 全局对象在哪些文件中被扩展（如 `handlers.tableRef`）
- 迁移后 `handlers` 的引用路径是否需要调整

**输出要求**：列出 handlers 的调用方和扩展点

## 四、风险分级

| 级别 | 定义 | 示例 |
|------|------|------|
| 🔴 高风险 | 迁移必出问题，需要预先设计兼容方案 | 全局变量改为模块导出后，HTML 中内联脚本访问不到 |
| 🟡 中风险 | 可能出问题，需要验证点 | 函数拆分到新文件后，循环依赖导致加载顺序错误 |
| 🟢 低风险 | 问题不大，按规范处理即可 | CSS 文件路径变更，HTML 中引用更新 |

## 五、输出格式

### 5.1 风险清单

对每个识别出的风险：
- 风险描述
- 涉及文件
- 风险等级（🔴/🟡/🟢）
- 触发条件（什么情况下会出问题）
- 应对建议

### 5.2 迁移优先级建议

基于风险评估，建议 9 个迁移任务的执行顺序：
- 哪些任务可以并行
- 哪些任务必须串行（前置依赖）
- 哪个任务风险最高，应该先做还是后做

### 5.3 验证检查点

每个任务完成后，必须验证的点：
- 浏览器控制台无报错
- 车卡流程能走到对应步骤
- 升级系统能正常导入

## 六、约束

- 只评估，不修改代码
- 每个风险必须给出具体文件和行号
- 不确定的风险标注"疑似"，不写成"确认"
- 评估时间控制在合理范围内，不无限深入

## 七、验收标准

- [ ] 全局变量映射表完整（定义位置 → 所有消费位置）
- [ ] 核心函数调用关系图清晰
- [ ] HTML script 加载顺序和依赖关系列出
- [ ] 风险清单不少于 5 项（如无则说明原因）
- [ ] 输出包含迁移优先级建议
- [ ] 输出包含每个任务的验证检查点

## 八、与 v0.4-002 的关系
