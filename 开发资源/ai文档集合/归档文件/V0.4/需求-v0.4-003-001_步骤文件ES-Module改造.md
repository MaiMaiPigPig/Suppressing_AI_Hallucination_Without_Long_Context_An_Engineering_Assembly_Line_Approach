# 需求-v0.4-003-001_步骤文件 ES Module 改造

## 一、目标与背景

**人类出这个需求的目的**：17 个步骤文件目前全是旧全局函数格式（`function renderXxxStep()`），没有任何 `export`。step-router.js 无法通过 import 获取渲染函数，这是阻塞项。

将 `creation/steps/` 下的 17 个步骤文件改造为 ES Module 格式，使 step-router.js 能正常 import 各步骤的渲染函数。

---

## 二、范围

### 包含
- 17 个步骤文件加 `export`
- step-router.js 改用 `import` 引用步骤文件
- 动态 import 方案（开发自行设计）

### 不包含
- 升级系统的步骤文件 → 002-G（延后）
- 函数重命名 → v0.5
- 步骤内部逻辑重构

---

## 三、任务清单

### 003-001-1. 步骤文件加 export

**来源**：`creation/steps/*.js`（17 个文件）

**工作内容**：
- 每个步骤文件的 `renderXxxStep()` 函数前加 `export`
- 保持函数名不变
- 保持函数签名不变

**示例**：
```js
// 改造前
function renderRaceStep() { ... }

// 改造后
export function renderRaceStep() { ... }
```

**v0.4 边界**：
- ✅ 加 export 关键字
- ❌ 不改函数名
- ❌ 不改函数签名

**验收标准**：
- [ ] 17 个步骤文件都有 export
- [ ] 浏览器控制台无报错

---

### 003-001-2. step-router.js 改用 import

**来源**：`creation/flow/step-router.js`

**工作内容**：
- 将 `renderStep()` 中的全局函数调用改为 import 引用
- 动态 import 方案由开发自行设计（懒加载或静态导入）

**v0.4 边界**：
- ✅ 改用 import 引用步骤文件
- ✅ 动态 import 方案开发自定
- ❌ 不改路由逻辑

**验收标准**：
- [ ] step-router.js 能正常 import 各步骤文件
- [ ] 步骤切换正常
