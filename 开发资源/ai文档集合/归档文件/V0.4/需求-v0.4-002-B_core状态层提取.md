# 需求-v0.4-002-B_core 状态层提取

## 一、目标与背景

**人类出这个需求的目的**：character 对象结构在 creation 和 upgrade 中各自定义，字段不一致。提取统一模型，确保两边数据结构一致。

将 `creation/character.js` 中的 character 状态管理逻辑提取到 `core/state/` 层。

---

## 二、范围

### 包含
- `character` 对象结构定义 → `core/state/character-model.js`
- `clearDataAfterStep()` + `unbind` 管理 → `core/state/character-state.js`
- `STEP_DATA_FIELDS` → `core/constants/character-constants.js`
- `ABILITY_NAMES` → `core/constants/character-constants.js`
- `upgrade/upgrade.js` 中的 `character` 定义删除，改为引用 core/ 层

### 不包含
- set/get API 封装 → v0.5
- 函数重命名 → v0.5

---

## 三、任务清单

### B1. 提取 core/state/character-model.js + core/constants/character-constants.js

**来源**：`creation/character.js` L6-35, L68-90, L641

**提取内容**：
- `character = {...}` 对象字面量（含默认值）→ `core/state/character-model.js`
- `STEP_DATA_FIELDS` 常量 → `core/constants/character-constants.js`
- `ABILITY_NAMES` 常量 → `core/constants/character-constants.js`

**v0.4 边界**：

- ❌ 不封装 getter/setter

**验收标准**：
