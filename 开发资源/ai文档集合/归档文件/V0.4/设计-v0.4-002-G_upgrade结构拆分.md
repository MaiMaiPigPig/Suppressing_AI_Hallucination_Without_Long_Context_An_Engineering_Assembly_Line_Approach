### 2.2 复用 creation/steps/ 文件

upgrade/ 复用以下 creation/ 的步骤文件：
- `steps/race.js`（查看种族信息）
- `steps/class.js`（查看职业信息）
- `steps/bonus.js`（查看背景加值）
- `steps/spells.js`（法术相关）
- `steps/sheet.js`（角色卡预览）

**复用方式**：直接 import，不复制代码。被复用文件需支持 `mode` 参数。

```javascript
// upgrade/steps/spell-update.js
import { renderSpellStep } from '../../creation/steps/spells.js';

export function renderSpellUpdateStep(container) {
  // 调用 creation 的法术渲染，传入升级模式参数
  renderSpellStep(container, { mode: 'upgrade' });
}
```

### 2.3 复用接口约束

被复用的 creation/steps/ 文件必须满足以下约束：

| 被复用文件 | 当前接口 | 需扩展 | 工作量 |
|-----------|---------|--------|--------|
| `steps/race.js` | `renderRaceStep(container)` | `renderRaceStep(container, { mode: 'upgrade' })` | 小：升级模式只读展示，不写入 character |
| `steps/class.js` | `renderClassStep(container)` | `renderClassStep(container, { mode: 'upgrade' })` | 小：同上 |
| `steps/bonus.js` | `renderBackgroundBonusStep(container)` | `renderBackgroundBonusStep(container, { mode: 'upgrade' })` | 小：同上 |
| `steps/spells.js` | `renderSpellStep(container)` | `renderSpellStep(container, { mode: 'upgrade' })` | 中：需区分"新增法术"与"全量选择" |
| `steps/sheet.js` | `renderCharacterSheet(container)` | `renderCharacterSheet(container, { mode: 'upgrade' })` | 小：升级模式显示升级后预览 |

**实现策略**：
1. 在 renderXxxStep 函数签名末尾添加 `options = {}` 参数
2. 通过 `options.mode === 'upgrade'` 判断分支
3. 升级模式下：只读展示、禁用选择、高亮变化项
4. 工作量归入 002-G 任务，不在 002-D 中处理

## 七、风险与回滚

| 风险 | 应对方案 |
|------|----------|
| creation/flow/lifecycle.js 路径依赖 | 确认相对路径：`upgrade/flow/` → `../../creation/flow/` |
| upgrade.js 2300 行拆分遗漏 | 逐函数对比，确保无遗漏 |
| 升级状态与创建状态冲突 | `upgradeState` 独立定义，不覆盖 character 对象 |
| 复用的 creation/steps/ 文件在升级模式下行为异常 | 添加 `mode: 'upgrade'` 参数控制分支逻辑（见 2.3 复用接口约束） |

**回滚方案**：保留原 upgrade.js 备份，恢复全局变量定义。
