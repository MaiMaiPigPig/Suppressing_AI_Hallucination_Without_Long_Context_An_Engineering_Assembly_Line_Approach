## 一、模块划分

### 1.1 文件结构

```
creation/ui/
├── progress-bar.js      # 进度条 + 步骤标签 + 导航按钮
├── selection-modal.js   # 选择弹窗（种族、职业、专长等）
└── currency-input.js    # 货币输入 + 职业套装货币自动填充
```

### 1.2 职责边界

| 文件 | 职责 | 不职责 |
|------|------|--------|
| progress-bar.js | 渲染进度条、更新步骤标签、更新按钮状态 | 不处理导航逻辑（只接收状态更新） |
| selection-modal.js | 打开/关闭弹窗、收集待选项、确认选择 | 不直接修改 character（通过回调） |
| currency-input.js | 渲染货币输入框、计算总额、自动填充套装货币 | 不管理货币数据来源 |

## 四、与 flow/ 层的交互

### 4.1 progress-bar.js 被 navigation.js 调用

```javascript
// creation/flow/navigation.js
import { updateProgress, updateButtons } from '../ui/progress-bar.js';

export function nextStep() {
  // ... 校验和步骤计算
  renderStep(nextStep);
  updateProgress(nextStep);   // 更新进度条
  updateButtons(nextStep);    // 更新按钮状态
}
```

### 4.2 selection-modal.js 被 steps/*.js 调用

```javascript
// creation/steps/race.js
import { openSelectionModal } from '../ui/selection-modal.js';
import { character } from '../core/state/character-model.js';

function onRaceCardClick(raceId) {
  openSelectionModal({
    title: '选择种族',
    items: dataCache.races,
    type: 'single',
    onConfirm: (selectedRace) => {
      character.race = selectedRace.id;
      nextStep(); // 由 flow/navigation.js 管理
    }
  });
}
```

## 七、风险与回滚

| 风险 | 应对方案 |
|------|----------|
| 弹窗样式丢失 | 确认 modal.css 已迁移到 styles/ 目录且路径正确 |
