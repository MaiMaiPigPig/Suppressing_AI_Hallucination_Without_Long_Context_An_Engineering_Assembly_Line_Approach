# 需求-v0.4-002-E_creation UI 层拆分

## 一、目标与背景

**人类出这个需求的目的**：UI 组件代码（进度条、弹窗、货币输入）混杂在 character.js 中，与流程逻辑耦合。拆分后 UI 组件可独立维护。

将 `creation/character.js` 中的 UI 组件逻辑拆分到 `creation/ui/` 层。

---

## 二、范围

### 包含
- `updateProgress()` + `updateStepLabel()` → `ui/progress-bar.js`
- `openSelectionModal()` + `collectPendingSelections()` + `processPendingSelections()` → `ui/selection-modal.js`
- `updateCurrency()` + `fillCurrencyFromPackage()` → `ui/currency-input.js`

### 不包含
- `collectPendingSelections()` 与 `addPendingSelectionsFromItem()` 合并 → v0.5
- 函数重命名 → v0.5
