## 一、目标

将 `TableChronicle/character/dnd_5r/creation/` 下的车卡代码，按逻辑层与功能层分离原则迁移到新目录结构。解决当前代码文件过长、职责混乱、该复用未复用的问题。

**本版本只解决结构问题（拆文件、抽共用层）。命名规范（函数重命名、变量改名、文件编号）在 v0.5 处理。**

## 二、版本边界（明确区分 v0.4 与 v0.5）

### v0.4（本版本）—— 结构重组

| 做什么 | 不做什么 |
|--------|---------|
| 拆文件（单文件不超过 800 行） | 不改函数名、变量名 |
| 抽共用逻辑到 `core/` 层 | 不给步骤文件加编号（如 `race.js` 不叫 `01-race.js`） |
| 调整 `upgrade/` 引用路径，共用 `core/` | 不改目录名（`core/` 已确定，不动） |
| 删除重复代码 | 不加 TypeScript 类型 |
| 迁移 CSS 文件位置 | 不改 CSS 类名 |

### v0.5（下版本）—— 命名规范落地

| 做什么 | 来源 |
|--------|------|
| 函数名去缩写（如 `calcMod` → `calculateModifier`） | 命名规范.txt |
| 变量名统一（同一概念全局唯一名字） | 开发生产准则第九条 |
| 步骤文件加编号（`race.js` → `01-race.js`） | 命名规范.txt |
| 核心概念统一命名（如 `feature` vs `trait`） | 命名规范.txt |

**测试注意**：v0.4 验收时，如果发现函数名、变量名不一致，不要报缺陷，这是 v0.5 的范围。
