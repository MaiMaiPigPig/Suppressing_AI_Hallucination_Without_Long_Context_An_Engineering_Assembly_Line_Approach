| 文件 | 职责 | 不职责 |
|------|------|--------|
| base.css | 全局基础样式（reset、字体、颜色变量） | 不包含步骤特定样式 |

| xxx.css（步骤） | 各步骤的特定样式 | 不包含其他步骤样式 |

## 二、样式拆分策略

### 2.1 从 character.css 拆分步骤样式

**原文件**：`creation/css/character.css`（假设包含所有步骤样式）

**拆分方法**：

```css
/* creation/styles/race.css */
/* 从 character.css 提取与种族选择相关的所有样式 */
.race-selection { ... }
.race-card { ... }
.race-card:hover { ... }
.race-card.selected { ... }

/* creation/styles/ability.css */
/* 从 character.css 提取与属性分配相关的所有样式 */
.ability-panel { ... }
.ability-score { ... }
.ability-modifier { ... }
/* ... */
```

### 2.2 命名规范

- 步骤样式类名前缀：`{step-name}-`（如 `.race-`、`.ability-`）
- 通用组件类名：保持原名称（如 `.modal`、`.btn`）
- 状态类名：保持原名称（如 `.selected`、`.disabled`）

## 四、迁移步骤

### 步骤 1：创建 styles/ 目录

1. 新建 `character/dnd_5r/creation/styles/` 目录
2. 新建 `character/dnd_5r/upgrade/styles/` 目录

1. `creation/css/base.css` → `creation/styles/base.css`
2. `creation/css/character.css` → `creation/styles/character.css`

1. 修改 `creation/character.html` 中的 `<link>` 路径
2. 修改 `upgrade/upgrade.html` 中的 `<link>` 路径

1. 确认 `creation/styles/` 下所有文件正确
2. 删除 `creation/css/` 目录

### 步骤 6：验证

1. 页面基础样式无回归
2. 各步骤样式正确加载
3. 浏览器控制台无 404（CSS 文件）

## 六、风险与回滚

| 风险 | 应对方案 |
|------|----------|
| 样式文件 404 | 检查 HTML 中 `<link>` 路径与文件实际位置一致 |
| 样式优先级冲突 | 保持选择器权重不变，只迁移位置 |
| 遗漏样式块 | 对比迁移前后的页面渲染效果 |
| 共用样式重复 | base.css 和 modal.css 考虑提取到 `core/styles/` |

**回滚方案**：恢复 `creation/css/` 目录，恢复 HTML 中的原路径。
