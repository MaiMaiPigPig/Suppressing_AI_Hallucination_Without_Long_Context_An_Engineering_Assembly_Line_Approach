### feat_debug.js 处理方案

**文件位置**：`creation/feat_debug.js`

**现状分析**：
- feat_debug.js 是特性调试辅助文件，用于开发阶段测试特性选择逻辑
- 当前通过 script 标签加载，定义全局调试函数
- 与正式功能无关，但占用加载资源

**v0.4 处理**：
1. 确认 feat_debug.js 的调用方（全局搜索 `feat_debug`）
2. 如无任何正式代码引用：
   - 从 `character.html` 的 script 标签中删除
   - 文件保留（不移除），但改为按需手动加载
3. 如有引用：
   - 将调试函数改为 ES Module 导出
   - 仅在开发模式下 import

**检查命令**：
```bash
# 检查是否有正式代码引用 feat_debug
grep -r "feat_debug" creation/ upgrade/ --include="*.js" --include="*.html"
# 预期：只在 character.html 的 script 标签和 feat_debug.js 自身有匹配
```
