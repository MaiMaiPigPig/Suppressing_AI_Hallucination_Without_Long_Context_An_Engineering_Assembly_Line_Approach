# 需求-v0.4-002-C_creation 流程层拆分

## 一、目标与背景

**人类出这个需求的目的**：character.js 长达 1256 行，同时管生命周期、步骤路由、导航控制，职责混乱。拆分后每个文件只干一件事。

将 `creation/character.js` 中的流程控制逻辑拆分到 `creation/flow/` 层。

---

## 二、范围

### 包含
- `renderStartStep()` + `startNewCharacter()` + `importCharacter()` + `loadCharacterFromJSON()` → `flow/lifecycle.js`
- `renderStep()` 路由表 → `flow/step-router.js`
- `nextStep()` + `prevStep()` + `goToStep()` + 校验 → `flow/navigation.js`
- HTML 内联事件改为事件委托

### 不包含
- 步骤渲染逻辑 → 002-D
- UI 组件逻辑 → 002-E
- 函数重命名 → v0.5
