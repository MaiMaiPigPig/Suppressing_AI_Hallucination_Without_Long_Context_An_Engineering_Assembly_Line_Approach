# 需求-v0.4-002-F_CSS 文件迁移

## 一、目标与背景

**人类出这个需求的目的**：CSS 文件目前散落在 `creation/css/` 目录，与 JS 文件不同步。迁移到 `creation/styles/` 目录，与 JS 文件同名对应，方便维护。

将 `creation/css/` 下的 CSS 文件迁移到 `creation/styles/` 目录。

---

## 二、范围

### 包含
- `base.css` → `styles/base.css`
- `character.css` → `styles/character.css`
- `modal.css` → `styles/modal.css`
- 各步骤样式拆分为 `styles/race.css`、`styles/ability.css` 等（与 JS 文件同名，不加编号）

### 不包含
- CSS 类名修改 → v0.5
- 样式逻辑修改

---

## 三、任务清单

### F1. 迁移基础样式文件

**来源**：`creation/css/`

**迁移内容**：
- `base.css` → `creation/styles/base.css`
- `character.css` → `creation/styles/character.css`
- `modal.css` → `creation/styles/modal.css`

**v0.4 边界**：
- ✅ 迁移文件位置
- ✅ 更新 HTML 中的 `<link>` 路径
- ❌ 不改 CSS 类名

**验收标准**：
- [ ] 基础样式文件在 `styles/` 目录下
- [ ] 页面基础样式无回归

---

### F2. 拆分步骤样式文件

**来源**：`creation/css/character.css`（步骤样式部分）

**拆分内容**：
- 从 `character.css` 中提取各步骤样式
- 拆分为 `styles/race.css`、`styles/ability.css` 等
- 与对应 JS 文件同名（不加编号）

**v0.4 边界**：
- ✅ 拆分样式文件
- ❌ 不改样式逻辑

**验收标准**：
- [ ] 各步骤样式文件在 `styles/` 目录下
- [ ] 各步骤页面样式无回归
- [ ] 删除旧 `creation/css/` 目录

---

## 四、总验收标准
