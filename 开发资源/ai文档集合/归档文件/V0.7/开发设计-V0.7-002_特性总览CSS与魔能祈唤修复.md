#### 步骤 A：改写 `checkPrerequisite`（13-review-renderer.js）

1. **先 `splitTopLevel` 拆分子条件，再逐条件剥离 `prerequisite()` 包裹**：

```javascript
export function checkPrerequisite(prereqStr) {
    if (!prereqStr || !character) return true;

    var inner = prereqStr;

    // 1. 先按 top-level 逗号拆分子条件（感知括号嵌套）
    var conditions = splitTopLevel(inner, ',');

    // 2. 逐条件处理：每个子条件先剥 prerequisite()，再正则匹配
    for (var ci = 0; ci < conditions.length; ci++) {
        var cond = conditions[ci].trim();
        if (!cond) continue;

        // 2a. 剥离该子条件的 prerequisite(...) 外层包裹
        var outerMatch = cond.match(/^prerequisite\((.+)\)$/i);
        if (outerMatch) cond = outerMatch[1];

        // 2b. 正则匹配 lv:class / spells / class_extra ...
    }
}
```

> **关键**：必须**先拆后剥**。多条件 prerequisite 如 `prerequisite(lv:class(11)=2),spells(class=11,lv=0,dice=1)+1`，`^prerequisite\((.+)\)$` 无法匹配整串（`)` 后面还有 `,spells(...)`），所以必须先用 `splitTopLevel` 按逗号切成 `["prerequisite(lv:class(11)=2)", "spells(...)+1"]`，再逐条剥。`translatePrereq` 同步按此顺序修正。

2. **实现 `splitTopLevel` 辅助函数**（感知括号嵌套深度，仅按 top-level 逗号切分）：

```javascript
function splitTopLevel(str, sep) {
    var parts = [];
    var depth = 0;
    var start = 0;
    for (var i = 0; i < str.length; i++) {
        if (str[i] === '(') depth++;
        else if (str[i] === ')') depth--;
        else if (str[i] === sep && depth === 0) {
            parts.push(str.substring(start, i).trim());
            start = i + 1;
        }
    }
    parts.push(str.substring(start).trim());
    return parts;
}
```

## 八、风险与回滚

| 风险 | 影响 | 缓解 |
|------|------|------|
| `resolveSpellFromRules` 依赖 spells.json 数据完整，若某特性 rules 指向不存在的法术 ID 则回退到原始 name/desc | 用户体验略粗糙 | 用 `|| null` 做安全回退，非致命 |
| `allFeatureBonuses.spells` 数据被完成页和导出页双处依赖，08-bonus.js 改动影响面广 | 若收集逻辑出错，两处同时崩 | 阶段 4 完成后用森林侏儒全流程验证特性区+法术栏+导出 PDF |
| translatePrereq 对 spells() 的翻译可能不精准（具体哪道戏法需查数据） | 界面文字略粗糙 | 简化为通用描述，后续可精确化 |
| `splitTopLevel` 新增函数可能被其他模块调用 | 命名冲突 | 两个文件各自内联定义，不 export，无冲突风险 |

### 回滚方案

所有改动集中在以下文件：
- `08-bonus.js`（applyParsedResultToBonus 新增 spells 收集）
- `13-review-renderer.js`（checkPrerequisite + splitTopLevel）
- `13-review-collector.js`（translatePrereq）
- `15-sheet-main.js`（法术栏合并 + 渲染改造 + indexOf 防弹 + resolveSpellFromRules）
- `16-export.js`（法术栏合并 + PDF 新增模块）
- `proficiency-link-resolver.js`（String 包裹）

每个阶段执行后 git commit，出现问题按 commit 回滚。
