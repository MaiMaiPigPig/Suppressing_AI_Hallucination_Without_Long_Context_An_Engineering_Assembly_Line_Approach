# 测试用例：导出/导入功能验证

**版本**：V0.7  
**创建时间**：2026-10-04  
**测试范围**：JSON 导出、PDF 导出、JSON 导入，覆盖下载→校验→导入→清理完整链路  
**测试数据目录**：`开发资源\角色卡\测试文件\`

---

## TC-01：JSON 导出 — 文件下载到指定目录

**前置条件**：车卡全流程已走完，停在步骤 16（完成页）。

**步骤**：
1. 清空 `开发资源\角色卡\测试文件\` 目录
2. 点击页面上的「导出 JSON」按钮
3. 等待文件下载完成，将下载的 `.json` 文件拷贝到 `开发资源\角色卡\测试文件\`
4. 确认目录中存在且仅有 1 个 `.json` 文件

**预期结果**：
- `开发资源\角色卡\测试文件\` 下有 1 个 `.json` 文件
- 文件名包含角色名或时间戳
- 文件大小 > 500 字节（空文件视为失败）

---

## TC-02：JSON 导出 — 文件内容完整性校验

**前置条件**：TC-01 通过，`测试文件` 目录下存在 JSON。

**步骤**：
1. 用 `json.load()` 解析文件
2. 校验顶层必需字段存在且非空：

| 字段 | 类型 | 说明 |
|------|------|------|
| `raceId` | int | 种族 ID，> 0 |
| `classId` | int | 职业 ID，> 0 |
| `backgroundId` | int | 背景 ID，> 0 |
| `name` | str | 角色名，非空 |
| `abilities` | dict | 6 项属性值，每项 ≥ 3 |
| `classSkills` | list | 职业技能列表 |
| `backgroundSkills` | list | 背景技能列表 |
| `selectedFeat` | int/None | 专长 ID |
| `shoppingItems` | list | 购物清单 |

3. 用 `raceId` 反查 `races.json`，确认种族名与页面上显示的种族一致
4. 用 `classId` 反查 `classes.json`，确认职业名一致
5. 用 `backgroundId` 反查 `backgrounds.json`，确认背景名一致

**预期结果**：
- 所有必需字段存在且类型正确
- 种族/职业/背景名与页面一致
- 属性值范围 3-20

## TC-04：PDF 导出 — 文件结构校验

**前置条件**：TC-03 通过，`测试文件` 目录下存在 PDF。

**步骤**：
1. 以二进制模式读取 PDF 文件
2. 检查前 5 字节是否为 `%PDF-`（PDF 魔术字节）
3. 读取末尾 2 KB，检查是否含 `%%EOF`（PDF 结束标记）
4. 在二进制内容中搜索页面显示的关键文本（角色名、种族名、职业名），这些文本可能以字面量形式存在于 PDF 流中

```
搜索项（页面已有数据）：
  - 角色名：self.data.character_name
  - 种族名：self.data.race_name
  - 职业名：self.data.class_name
```

**预期结果**：
- 魔术字节 `%PDF-` 存在
- 结束标记 `%%EOF` 存在
- 角色名/种族名中至少 2 项可在二进制内容中搜到（html2canvas 生成的 PDF 文本搜索性有限，不强求全部命中）

## TC-05：JSON 导入 — 从测试目录加载并恢复角色

**前置条件**：TC-01/TC-02 通过，`测试文件` 目录下存在合法 JSON。

**步骤**：
1. 从 `开发资源\角色卡\测试文件\` 读取 JSON 文件，`json.load()` 解析
2. 刷新浏览器页面，回到欢迎页
3. 等待 `loadCharacterFromJSON` 函数就绪
4. 通过 `driver.execute_script("loadCharacterFromJSON(arguments[0]);", data)` 绕过文件对话框直接导入
5. 等待页面跳转到步骤 15（角色卡展示页）
6. 确认 `self.get_step() == 15`

**预期结果**：
- 导入后跳转到步骤 15
- 页面不报 JS 错误

---

## TC-06：JSON 导入 — 导入后数据一致性验证

**前置条件**：TC-05 通过，已导入并停在步骤 15。

**步骤**：
1. 获取页面 body 文本
2. 逐项核对页面展示与 JSON 数据：

| 验证项 | JSON 字段 | 页面预期 |
|--------|-----------|----------|
| 角色名 | `name` | 出现在 body 文本中 |
| 种族 | `raceId` → 反查 races.json | 种族名出现在 body 文本中 |
| 职业 | `classId` → 反查 classes.json | 职业名出现在 body 文本中 |
| 背景 | `backgroundId` → 反查 backgrounds.json | 背景名出现在 body 文本中 |
| 属性值 | `abilities` | 至少 1 项属性值出现在页面上 |

**预期结果**：
- 全部 5 项验证通过
- 导入回显的数据与导出时的数据一致

## 执行顺序与依赖

```
TC-01 (JSON下载) ──→ TC-02 (JSON校验)
                         │
TC-03 (PDF下载) ──→ TC-04 (PDF校验)
                         │
                    TC-05 (JSON导入) ──→ TC-06 (导入验证)
                                             │
                                        TC-07 (清理)
```

- TC-01/03 可并行
- TC-02 依赖 TC-01
- TC-04 依赖 TC-03
- TC-05 依赖 TC-01/02（需要合法 JSON）
- TC-06 依赖 TC-05
- TC-07 最后执行

## 脚本实现要点（不动代码，仅列出需要的方法）

| 方法 | 用途 |
