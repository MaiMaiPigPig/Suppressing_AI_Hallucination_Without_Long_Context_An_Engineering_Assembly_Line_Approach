## 🟠 中等 — 3 个测试断言值与代码实际行为不一致

「第八章测试用例设计细则」是给开发直接照着写测试的规格表。以下 3 个用例的期望值写错了，照抄到代码里会导致测试结果不反映真实行为。

---

### 缺陷 1：`escapeHtml(0)` 期望 `'0'`，实际返回 `''`

**设计文档写**（[8.1 表格]()

> | 边界：数字 | `0` | `'0'` |

**代码实际行为**（[html.js:17](file:///f:/跑团工具/TableChronicle/character/dnd_5r/utils/html.js#L17)）：

```js
export function escapeHtml(text) {
    if (!text) return '';   // ← 0 是 falsy，走这里
    return String(text)...
}
```

`0` 在 JavaScript 中是 falsy 值，`!0` 为 `true`，函数直接返回 `''`，不会进入 `String(0)` → `'0'` 的路径。

**预期修正**：期望值改为 `''`。

---

### 缺陷 2：`replacePlaceholdersInText` 空 item 期望 `'伤害 ?'`，实际返回原文本

**设计文档写**（[8.6 表格]()

> | `'伤害 %x%'` | `{}`（无 rules/dice） | `'伤害 ?'` |

**代码实际行为**（[loader.js:111-L118](file:///f:/跑团工具/TableChronicle/character/dnd_5r/core/data/loader.js#L111-L118)）：

```js
export function replacePlaceholdersInText(text, item) {
    if (!text || !item) return text || '';
    // item={} 无 rules 字段 → xRaw=''（dice 也为 undefined）
    // xValues=[], yValues=[]
    // if (xValues.length === 0 && yValues.length === 0) return text;  ← 走这里
}
```

当 `item = {}` 既没有 `rules` 也没有 `dice` 字段时，`xValues` 和 `yValues` 都为空数组，函数在 [L118] 处直接返回原始文本 `'伤害 %x%'`，而不是把 `%x%` 换成 `?`。

**预期修正**：期望值改为 `'伤害 %x%'`（原文本不替换）。

### 缺陷 3：`translateProperties('99')` 期望 `'[99]'`，实际返回 `'99'`

**设计文档写**（[8.4 表格]()

> | `translateProperties('99')` | 无效 ID fallback | `'[99]'` |

**代码实际行为**（[dictionary.js:17-L24](file:///f:/跑团工具/TableChronicle/character/dnd_5r/core/data/dictionary.js#L17-L24)）：

```js
return parts.map(part => {
    const match = part.match(/^(\d+)(.*)$/);
    if (match) {
        const id = parseInt(match[1]);
        const name = PROPERTY_MAP[id];
        if (name) {          // ← 99 不在映射中，name 为 undefined
            return name + extra;
        }
    }
    return part;             // ← 走这里，直接返回原始字符串 '99'
}).join('、');
```

ID 99 不在 `PROPERTY_MAP` 中，`name` 为 `undefined`，`if (name)` 为 `false`，走到底部 `return part`，返回的是原始数字字符串 `'99'`，不带方括号。

`[id]` 的方括号格式在设计文档其他部分的 fallback 描述中出现过，但代码并未实现该格式。

**预期修正**：期望值改为 `'99'`（不带方括号）。如产品需要方括号格式作为无效 ID 标识，则应视为功能新增而非测试修正。
