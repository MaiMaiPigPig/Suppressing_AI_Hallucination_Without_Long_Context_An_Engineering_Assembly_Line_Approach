# 需求-V0.7-006：特性总览 CSS 失效与回归测试

## 一、参考需求来源

- 需求-V0.7-001_v0.5收尾与遗漏处理（已归档 V0.7，见 3.3d/3.7 节）

## 二、需求背景

特性总览页 CSS 样式失效（已修复）；车卡完成页内容不齐全，含 `spells(id=N)` 规则的种族特性未渲染；PDF 导出内容与完成页不一致。

## 三、处理事项

### 3.1 特性总览页 CSS 样式修复 ✅ 已完成（2026-10-03）

**现象**：特性总览页渲染后 CSS 样式未生效，页面元素无样式。

**处理方案**：
- 排查 `13-review.js` 引用的 CSS 文件路径是否正确（HTML 中 `<link>` 或 JS 中动态加载路径），确认文件存在且未被步骤重命名遗漏
- 排查特性总览渲染 DOM 后是否动态插入 CSS 但插入时机/位置错误（如插入到错误容器、页面切换时样式被清空等）
- 若 CSS 文件本身无问题，排查页面渲染函数是否未触发样式注入逻辑

**验收标准**：
- 车卡流程走到特性总览页（顺延后步骤 13），元素具有正确 CSS 样式（字体、颜色、间距、卡片布局等与设计一致）
- 切换到其他步骤再切回，样式不丢失

---

### 3.2 完成页（顺延后步骤 15）含 `spells(id=N)` 规则的种族特性未渲染

**现象**：角色完成页（`15-sheet.js`）内容不齐全。以森林侏儒为例，种族链接三个特性（47/48/49），但只渲染了 49（纯描述），47（法术:次级幻象）和 48（法术:动物交谈）均未展示——这两个特性的共性为 `rules: "spells(id=N)"`。

**与 V0.7-001 3.3d 的关联**：根因同为 `spells(id=N)` 格式未被解析器支持。V0.7-001 3.3d 处理的是特性总览页"全部法术弹出来让你选"的问题，本项处理的是完成页**完全不渲染**的问题——两处需要一起修。

**处理方案**：
- 排查完成页渲染时，对 `rules: "spells(id=N)"` 的特征是否因解析失败而被跳过（不渲染、不展示）
- 确认 `spells(id=N)` 解析器修复后（V0.7-001 3.3d），完成页是否自动恢复正常渲染
- 若仍有问题，排查完成页读取特征数据时是否只认特定 `rules` 格式（如只认 `chain(...)` 不认 `spells(...)`）

**验收标准**：
- 选择森林侏儒完成车卡，完成页「特性·专长」区块展示三项：次级幻象、动物交谈、森林侏儒，无遗漏
- 其他含 `spells(id=N)` 规则的种族（如阿斯莫 spells(id=11)）同样正常渲染

---

### 3.3 导出 PDF 内容对齐完成页

**现象**：导出 PDF 的内容不齐全，未覆盖完成页展示的全部内容。

**处理方案**：
- 导出 PDF 的数据源应与完成页使用同一份角色汇总数据，确保内容一致性
- 排查 `16-export.js` 的数据读取逻辑，确认导出模板覆盖完成页的全部展示模块（属性、技能、特性、熟练、法术、装备等）
- 若导出模板有独立的渲染逻辑，对齐完成页的展示模块清单，补上缺失的模块

**验收标准**：
- 导出 PDF 的内容与完成页展示内容一致，无缺失模块
- 完成页新修复的种族特性也能在 PDF 中正常展示
