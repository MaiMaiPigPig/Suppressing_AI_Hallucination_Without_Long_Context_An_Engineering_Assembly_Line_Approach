```javascript
// sheet-renderer.js (export) 和 export.js (local) — 实现相同
function translateProperties(props) {
    if (!props || props === '—' || props === '---') return '—';
    const propStr = Array.isArray(props) ? props.join(',') : String(props);
    const parts = propStr.split(',').map(p => p.trim()).filter(Boolean);
    const PROPERTY_MAP = window.PROPERTY_MAP || {};
    return parts.map(part => {
        const match = part.match(/^(\d+)(.*)$/);
        if (match) {
            const id = parseInt(match[1]);
            const name = PROPERTY_MAP[id];
            if (name) {
                const extra = match[2] || '';
                return name + extra;
            }
        }
        return part;
    }).join('、');
}
```

【规避措施】提取时直接移动，无需处理差异  
【验证方法】提取后确认旧位置改为 import，export 功能不变

### 7.1 ⚠️ `calcMod` 在 `export.js` 中的重复定义

【风险项】`export.js` 中存在 `calcMod` 的独立副本，与 `ability.js` 重复  
【风险等级】**中**  
【影响范围】`export.js:L310`、`ability.js:L17`、`sheet-main.js`  
【具体场景】当前状态：
- `ability.js` 导出 `calcMod`（正式定义）
- `sheet-main.js` 从 `ability.js` import（正确）
- `export.js` 自己定义了一个本地 `function calcMod(score) { ... }`（重复）

如果 v0.5 只做"重命名"（`calcMod` → `calculateModifier`），`export.js` 中会有两处需改：
1. 本地定义 `function calcMod` → `function calculateModifier`（改名）
2. 然后还需要**删除此本地定义，改为 `import { calculateModifier } from './ability.js'`**（去重）

这是"改名"和"去重"两个操作叠加，容易遗漏去重步骤。

【规避措施】改名清单中为 `calcMod` 单独加一个"去重"标记，确保 `export.js` 的本地定义被删除并改为 import  
【验证方法】改名后 `grep "function calcMod\|function calculateModifier" creation/steps/export.js` 应返回 0 结果
