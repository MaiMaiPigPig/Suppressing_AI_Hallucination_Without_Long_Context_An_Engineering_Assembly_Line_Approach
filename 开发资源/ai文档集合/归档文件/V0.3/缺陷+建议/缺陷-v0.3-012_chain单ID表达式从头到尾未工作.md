## 一句話

v0.3 修了 `proficiency(id=443→460)` 范围格式的两条 chain（奥法骑士/诡术师），但 class_features.json 里还有 **2 条** `table(id=X)` 单 ID 格式的 chain——它们在任何版本中都没有被正确处理过。

---

## 缺陷描述

`class_features.json` 中 `chain` 字段支持三种已知格式：

| 格式 | 示例 | 当前状态 |
|------|------|:---:|
| 逗号数字 | `"4,5,6"` | ✅ 一直能工作 |
| 范围表达式 | `"proficiency(id=443→460)"` | ✅ v0.3 修复后能工作 |
| **单 ID 表达式** | **`"tools(id=24)"`** | ❌ **从未能工作** |
| **单 ID 表达式** | **`"monsters(id=15)"`** | ❌ **从未能工作** |

`"tools(id=24)"` 和 `"monsters(id=15)"` 进入 `processChainReferences` 后的路径：

```
输入: "tools(id=24)"
  ↓
新正则: /(\w+)\(id=(\d+)→(\d+)\)/.exec("tools(id=24)")
  ↓ 不匹配（没有 →）
  ↓
旧回退: "tools(id=24)".split(',').map(parseInt).filter(notNaN)
  ↓
parseInt("tools(id=24)") → NaN → filter 移除
  ↓
结果: 空数组，循环不执行，chain 被静默丢弃
```

## 证据

### 证据 1：id=279 — 逸闻学院·操命本事

[class_features.json L5007-L5022](file:///f:/跑团工具/TableChronicle/data/json/class_features.json#L5007-L5022)：
```json
{
    "id": 279,
    "name": "操命本事",
    "class": 6,
    "level": 3,
    "subclass": 44,
    "rules": "skills(id=21)",
    "chain": "tools(id=24)",
    ...
}
```

该特性是吟游诗人·逸闻学院 Lv3 特性。`rules: "skills(id=21)"` 提供了技能熟练项选择，`chain: "tools(id=24)"` 本意应是额外提供工具熟练项。但 chain 从未生效，工具熟练项可能遗漏。

### 证据 2：id=333 — 牧境·原初行侣

[class_features.json L5961-L5976](file:///f:/跑团工具/TableChronicle/data/json/class_features.json#L5961-L5976)：
```json
{
    "id": 333,
    "name": "原初行侣",
    "class": 8,
    "level": 3,
    "subclass": 6,
    "rules": "monsters(id=13)",
    "dice": "monsters(id=14)",
    "chain": "monsters(id=15)",
    "extra": "class_extra_all"
}
```

该特性是德鲁伊·牧境 Lv3 特性。带有 `"extra": "class_extra_all"` 标记，说明与升级系统的 class_extra 选择联动。`chain: "monsters(id=15)"` 如果正确工作，会为 collectSelectionsFromSource 提供额外的怪物数据选择。

### 证据 3：所有历史版本均未正确处理

processChainReferences 的解析逻辑在 v0.2 / v0.3 的演进中一直是：
- v0.2: `split(',').map(parseInt).filter(notNaN)`
- v0.3: 先尝试范围正则，不匹配则回退到 v0.2 的逻辑

无论是哪个版本，`"tools(id=24)"` 和 `"monsters(id=15)"` 都经过 `parseInt → NaN → 丢弃` 的路径。这是从数据采用 `table(id=X)` 格式的第一天起就存在的缺陷。

## 影响范围

| 影响 | 详情 |
|------|------|
| **id=279 操命本事** | 逸闻学院 Lv3 可能缺少工具熟练项选择 |
| **id=333 原初行侣** | 牧境 Lv3 可能缺少怪物数据引用，影响升级系统的 class_extra 选择 |
| **破坏面** | 两条都是子职特性，仅影响特定子职的特定等级，不属于全局性问题 |

## 建议

本缺陷应与缺陷-v0.3-009（表名被捕获后丢弃）一起处理。009 建议在范围解析中也使用表名定位目标表——如果实现，单 ID 格式可以复用同一套路径：

```javascript
// 把范围正则扩展为同时支持单 ID 和范围：
const tableRefMatch = chainStr.match(/(\w+)\(id=(\d+)(?:→(\d+))?\)/);
if (tableRefMatch) {
    const tableName = tableRefMatch[1];  // "tools" / "monsters"
    const startId = parseInt(tableRefMatch[2], 10);
    const endId = tableRefMatch[3] ? parseInt(tableRefMatch[3], 10) : startId;
    // ...
}
```

如果认为这两条数据不影响核心功能，也可以暂不处理——但需确认车卡和升级过程中没有遗漏 UI 选项或数据条目。
