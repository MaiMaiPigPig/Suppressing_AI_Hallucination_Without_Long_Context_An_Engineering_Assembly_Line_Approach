# 需求-v0.7-001_新增单元测试脚本

## 一、目标

为 dnd_5r 前端代码建立单元测试体系，覆盖核心工具函数和数据处理逻辑，减少人工回归测试成本。

## 二、前置依赖

- [ ] v0.6 全部任务已完成并验收通过

## 三、范围

### 包含
- `core/` 下纯函数（无 DOM 依赖、无全局状态依赖）
- `utils/` 下工具函数（`escapeHtml()`、`currency.js` 等）
- `core/data/dictionary.js` 中的数据映射函数

### 不包含
- 涉及 DOM 操作的步骤渲染逻辑
- 涉及全局状态（`window.character`）的函数
- `upgrade/` 模块
- handlers 层（规则引擎，需单独评估测试策略）

## 四、测试框架

待定（需技术评估）：
- 选项 A：Jest（Node 环境，适合纯函数）
- 选项 B：Vitest（Vite 生态，与前端工程更贴合）

## 五、首批测试目标

| 模块 | 函数 | 测试要点 |
|------|------|----------|
| `utils/html.js` | `escapeHtml()` | 特殊字符转义、null/undefined 处理 |
| `utils/currency.js` | `parsePrice()` | 各种货币格式解析 |
| `utils/currency.js` | `toCP()` | 换算正确性 |
| `utils/currency.js` | `formatCurrency()` | 格式化输出 |
| `core/data/dictionary.js` | `translateDamageType()` | 映射完整性 |
| `core/data/dictionary.js` | `translateProperties()` | 映射完整性 |
| `core/data/` | 数据加载相关 | 缓存命中、错误处理 |

## 六、验收标准

- [ ] 测试框架已搭建，运行命令写入 `package.json`
- [ ] 首批测试用例全部通过
- [ ] CI/CD 或本地可一键运行测试
- [ ] 测试覆盖率报告可生成

## 七、备注

本需求为技术债务偿还，不新增业务功能。测试范围从纯函数开始，逐步扩展。
