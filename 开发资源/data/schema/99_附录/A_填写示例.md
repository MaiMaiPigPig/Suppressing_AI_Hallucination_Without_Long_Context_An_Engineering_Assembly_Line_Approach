# 附录 A：完整填写示例

本文档展示 AI 从**原始规则文本**到**最终 CSV 数据**的完整流程。

---

## 示例 1：从 DND 规则文本提取法术数据

### 步骤 1：输入（原始规则文本）

```
燃烧之手 Burning Hands
1环塑能法术
施法时间：1动作
施法距离：自身（15尺锥状）
法术成分：V, S
持续时间：瞬时

你向前喷射出一片火焰。处于15尺锥状区域内的生物必须进行一次敏捷豁免。
豁免失败者受到3d6点火焰伤害，豁免成功者受到一半伤害。
在此锥状区域内的未被着装或携带的易燃物件会开始燃烧。

升环施法。你使用的法术位每比一环高一环，此法术的伤害就提升1d6。
```

### 步骤 2：AI 分析

**1. 基础信息提取**
- 名字：燃烧之手
- 英文名：Burning Hands
- 学派：塑能 → 查字典表 → 11
- 等级：1环 → 1
- 施法时间：1动作 → action
- 距离：自身（15尺锥状）→ range=0（自身为原点）, range_unit=self
- 成分：V, S → comp_v=1, comp_s=1, comp_m=0
- 持续时间：瞬时 → duration_unit=instant

**2. 目标类型判断（用决策树）**
```
法术需要选择目标？
  └─ 否 → 影响施法者自身？
        └─ 否 → 影响一个固定点/区域？
              └─ 是 → 判断形状：
                    └─ 锥形扩散 → target_type = cone
```
- target_type = cone
- target_size = 15（锥状长度，英尺）
- target_size2 = 留空（锥形不需要第二尺寸）

**3. 效果分析**
- 效果类型：造成伤害 → effect_type = damage
- 伤害类型：火焰 → 查字典表 → fire
- 豁免：敏捷 → 查字典表 → 5
- 豁免成功：一半伤害 → save_success = half
- 攻击检定：不需要 → attack_roll = 0
- 骰娘互动：3d6，升环+1d6 → "3d6,+1d6"
- 升环效果：level:+1,+1d6

**4. 职业判断**
- 从规则书查得：术士、法师可学
- 查职业表：术士=10, 法师=12
- classes = "10,12"

**5. AI规则编写**
```
目标：自身前方15尺锥状区域。判定：范围内每名生物敏捷豁免，失败受全额伤害，成功半伤。效果：3d6火焰伤害，可点燃无主易燃物。特殊：升环每环+1d6。
```

### 步骤 3：输出 CSV

```csv
id,名字,英文名,学派,等级,职业,施法时间,施法时间单位,施法距离,距离单位,仪式,成分_语言,成分_姿势,成分_材料,材料描述,材料价值,材料消耗,专注,持续时间,持续时间单位,升环效果,骰娘互动,伤害类型,DLC,详情,目标类型,目标尺寸,目标尺寸2,目标数量,豁免类型,豁免成功,攻击检定,效果类型,AI规则
41,燃烧之手,Burning Hands,11,1,10、12,action,,0,self,0,1,1,0,,0,0,0,,instant,level:+1,+1d6,3d6,fire,phb,"你向前喷射出一片火焰。处于15尺锥状区域内的生物必须进行一次敏捷豁免。豁免失败者受到3d6点火焰伤害，豁免成功者受到一半伤害。在此锥状区域内的未被着装或携带的易燃物件会开始燃烧。",cone,15,,,5,half,0,damage,"目标：自身前方15尺锥状区域。判定：范围内每名生物敏捷豁免，失败受全额伤害，成功半伤。效果：3d6火焰伤害，可点燃无主易燃物。特殊：升环每环+1d6。"
```

### 步骤 4：自检

```
□ ID 在范围内？ → 41（本体数据，1-9999）✅
□ 必填字段都填了？ → 是 ✅
□ 职业 ID 存在？ → 10=术士, 12=法师 ✅
□ 目标类型正确？ → cone（锥形）✅
□ 列表用英文逗号？ → "10,12" ✅
□ 数值字段无文本？ → 等级=1, 目标尺寸=15 ✅
```

## 示例 2：从规则文本提取状态效果

### 步骤 1：输入（原始规则文本）

```
恐慌 Frightened
- 恐慌的生物无法进行自愿移向恐惧源的移动。
- 恐慌的生物在攻击检定和属性检定上具有劣势。
- 持续时间：通常由造成恐慌的法术/特性决定。
- 常见解除方式：远离恐惧源、成功豁免、法术结束。
```

### 步骤 2：AI 分析

**1. 基础信息**
- 名字：恐慌
- 英文名：Frightened
- 分类：心智 → 查字典表 → 1

**2. 效果分析**
- 动作影响：无法自愿接近恐惧源 → action_effects = "cant_move_toward_source"
- 检定影响：攻击和属性检定劣势 → check_effects = "attack_disadvantage,ability_check_disadvantage"
- 持续时间：通常由来源决定 → duration_type = special
- 自动解除：远离恐惧源 → auto_remove = "custom"（具体看来源描述）

**3. 属性影响**
```json
{
  "attack_roll": {"type": "disadvantage", "value": true},
  "ability_check": {"type": "disadvantage", "value": true}
}
```

### 步骤 3：输出 CSV

```csv
id,名字,英文名,分类,图标,颜色,持续时间类型,持续时间数值,可叠加,叠加规则,自动解除条件,对属性的影响,对动作的影响,对检定的影响,豁免可解除,豁免类型,豁免DC,免疫来源,详情,战斗提示,DLC
2,恐慌,Frightened,1,frighten,#8b4513,special,,0,,custom,"{""attack_roll"":{""type"":""disadvantage"",""value"":true},""ability_check"":{""type"":""disadvantage"",""value"":true}}",cant_move_toward_source,"attack_disadvantage,ability_check_disadvantage",0,,,,"恐慌的生物无法进行自愿移向恐惧源的移动。恐慌的生物在攻击检定和属性检定上具有劣势。","攻击和检定劣势",phb
```

## 示例 3：DLC 新增法术

### 场景

DLC "深海秘境" 新增一个法术"水压爆裂"。

### DLC 信息

```json
// manifest.json
{
  "id": "dlc_01",
  "name": "深海秘境",
  "version": "1.0.0",
  "depends_on": ["phb"],
  "id_prefix": 10000,
  "tables": {
    "新增": ["spells"]
  }
}
```

### 输入规则文本

```
水压爆裂 Hydraulic Burst
2环变化法术
施法时间：1动作
施法距离：60尺
法术成分：V, S, M（一滴水）
持续时间：瞬时

你指定施法距离内一点，高压水流从该点爆发。处于以该点为源点的10尺半径球状区域内的每个生物必须进行一次力量豁免。
豁免失败者受到4d8点钝击伤害并被推离10尺。豁免成功者只受到一半伤害，不会被推离。

升环施法：你使用的法术位每比二环高一环，此法术的伤害就增加1d8。
```

### AI 分析要点

- **ID**：DLC 前缀 10000，第一个法术 → 10000
- **目标类型**：sphere（球形）
- **目标尺寸**：10（半径）
- **效果类型**：damage（伤害）+ 推离效果（特殊，写在详情中）
- **伤害类型**：钝击 → 查字典表 → bludgeoning

### 输出 CSV（仅包含本 DLC 数据）

```csv
id,名字,英文名,学派,等级,职业,施法时间,施法时间单位,施法距离,距离单位,仪式,成分_语言,成分_姿势,成分_材料,材料描述,材料价值,材料消耗,专注,持续时间,持续时间单位,升环效果,骰娘互动,伤害类型,DLC,详情,目标类型,目标尺寸,目标尺寸2,目标数量,豁免类型,豁免成功,攻击检定,效果类型,AI规则
10000,水压爆裂,Hydraulic Burst,14,2,4、12,action,,60,feet,0,1,1,1,一滴水,0,0,0,,instant,level:+1,+1d8,4d8,bludgeoning,dlc_01,"你指定施法距离内一点，高压水流从该点爆发。处于以该点为源点的10尺半径球状区域内的每个生物必须进行一次力量豁免。豁免失败者受到4d8点钝击伤害并被推离10尺。豁免成功者只受到一半伤害，不会被推离。",sphere,10,,,2,half,0,damage,"目标：60尺内一点，10尺半径球状区域。判定：范围内每名生物力量豁免，失败受全额伤害并被推离10尺，成功半伤不被推离。效果：4d8钝击伤害。特殊：升环每环+1d8。"
```

### 关键注意

- ID = 10000（在 DLC 前缀范围内）
- DLC 列 = "dlc_01"（不是 phb）
- 职业 = "4,12"（德鲁伊和法师，假设这个 DLC 给这两个职业）
- 这个 CSV 文件只包含这一条数据（只放 DLC 新增的内容）

## 示例 4：覆盖本体数据

### 场景

DLC "平衡补丁" 认为火球术太强了，想修改伤害。

### 做法

使用**和本体相同的 id**，引擎会自动用 DLC 版本覆盖。

```csv
id,名字,英文名,学派,等级,职业,施法时间,施法时间单位,施法距离,距离单位,仪式,成分_语言,成分_姿势,成分_材料,材料描述,材料价值,材料消耗,专注,持续时间,持续时间单位,升环效果,骰娘互动,伤害类型,DLC,详情,目标类型,目标尺寸,目标尺寸2,目标数量,豁免类型,豁免成功,攻击检定,效果类型,AI规则
1,火球术,Fireball,11,3,10、12,action,,150,feet,0,1,1,1,一小块硫磺,0,0,0,,instant,level:+1,+1d6,6d6,fire,dlc_balance,"【平衡调整】火球术伤害从8d6降至6d6。你指定施法距离内一点...",sphere,20,,,5,half,0,damage,"目标：施法距离内一点，20尺半径球状区域。判定：敏捷豁免。效果：6d6火焰伤害（平衡调整）。特殊：升环每环+1d6。"
```

注意：
- id = 1（和本体火球术相同）
- 骰娘互动从 "8d6" 改为 "6d6"
- DLC 列标注来源
- 详情中注明 "【平衡调整】" 方便玩家识别
