# 附录 C：常见错误与避坑指南

本文档汇总 AI 和人类在填写数据时最常犯的错误。

---

## 一、格式类错误

### 错误 1：使用中文顿号分隔列表

```
❌ 错误：职业 = "10、12、13"
✅ 正确：职业 = "10,12,13"

❌ 错误：特性chain: = "1,2,3"
✅ 正确：特性chain: = "1,2,3"（这个是对的，但注意是英文逗号）
```

**原因**：CSV 解析器只认英文逗号。

### 错误 2：数值字段混入单位

```
❌ 错误：施法距离 = "150尺"
✅ 正确：施法距离 = "150"（距离单位 = "feet"）

❌ 错误：目标尺寸 = "20尺"
✅ 正确：目标尺寸 = "20"

❌ 错误：材料价值 = "25金币"
✅ 正确：材料价值 = "25gp"
```

**原因**：数值字段必须是纯数字，单位在单独的字段中。

### 错误 3：布尔值不标准

```
❌ 错误：仪式 = "是"
❌ 错误：仪式 = "true"
✅ 正确：仪式 = "1"

❌ 错误：专注 = "否"
❌ 错误：专注 = "false"
✅ 正确：专注 = "0"
```

**原因**：系统用 0/1 表示布尔值。

### 错误 4：文本中的逗号未包裹

```
❌ 错误：
id,名字,详情
1,火球术,造成8d6火焰伤害,可点燃物品

✅ 正确：
id,名字,详情
1,火球术,"造成8d6火焰伤害,可点燃物品"
```

**原因**：CSV 中逗号是分隔符，文本中的逗号必须用双引号包裹整列。

## 二、引用类错误

### 错误 5：引用不存在的 ID

```
❌ 错误：职业 = "10,99"（99 号职业不存在）
✅ 正确：职业 = "10,12"

❌ 错误：link(999)（引用表没有 999）
✅ 正确：link(58)（确认引用表有 58）
```

**原因**： broken link 会导致程序运行时错误。

### 错误 6：用名字代替 ID

```
❌ 错误：职业 = "法师,术士"
✅ 正确：职业 = "10,12"

❌ 错误：学派 = "塑能"
✅ 正确：学派 = "11"
```

**原因**：程序只认 ID，不认名字。

### 错误 7：ID 冲突

```
❌ 错误：DLC 数据 id = 100（在本体范围内）
✅ 正确：DLC 数据 id = 10000（在 DLC 范围内）

❌ 错误：同一 DLC 内两个法术都用 id = 10001
✅ 正确：id = 10001, 10002, 10003...
```

**原因**：ID 必须全局唯一。

## 三、语义类错误

### 错误 8：目标类型判断错误

```
❌ 错误：火球术 target_type = "single"
✅ 正确：火球术 target_type = "sphere"

❌ 错误：燃烧之手 target_type = "self"
✅ 正确：燃烧之手 target_type = "cone"

❌ 错误：交友术 target_type = "sphere"
✅ 正确：交友术 target_type = "single"
```

**原因**：目标类型决定战斗模块渲染什么形状的范围框，错了会导致玩家无法正确施法。

### 错误 9：效果类型判断错误

```
❌ 错误：祝福术 effect_type = "healing"
✅ 正确：祝福术 effect_type = "buff"

❌ 错误：妖火 effect_type = "damage"
✅ 正确：妖火 effect_type = "debuff"
```

**原因**：效果类型决定战斗模块的结算逻辑。

### 错误 10：豁免成功效果写错

```
❌ 错误：火球术 save_success = "damage_zero"
✅ 正确：火球术 save_success = "half"

❌ 错误：交友术 save_success = "half"
✅ 正确：交友术 save_success = "effect_zero"
```

**原因**：火球术豁免成功是"半伤"，交友术豁免成功是"不受效果"。

## 四、DLC 类错误

### 错误 11：DLC 数据混入本体

```
❌ 错误：DLC 的 CSV 文件包含本体数据（如火球术 id=1）
✅ 正确：DLC 的 CSV 只包含新增/覆盖的数据
```

**原因**：引擎会自动合并，DLC 不需要复制本体数据。

### 错误 12：覆盖不写 DLC 标识

```
❌ 错误：覆盖本体火球术，但 DLC 列 = "phb"
✅ 正确：覆盖本体火球术，DLC 列 = "dlc_01"
```

**原因**：需要区分数据来源，方便调试和版本管理。

### 错误 13：manifest.json 缺失

```
❌ 错误：DLC 目录下没有 manifest.json
✅ 正确：每个 DLC 必须有 manifest.json
```

**原因**：引擎靠 manifest.json 识别和加载 DLC。

## 五、AI 特有错误

### 错误 14：过度推断

```
❌ 错误：规则文本只说"造成火焰伤害"，AI 写成 "8d6火焰伤害"
✅ 正确：如果规则文本没有明确数值，留空或写 "见详情"
```

**原因**：AI 不应该编造数据。不确定时留空，让人工补充。

### 错误 15：忽略边界情况

```
❌ 错误：只写了法术的主要效果，忽略升环、特殊条件等
✅ 正确：完整提取所有规则信息
```

### 错误 16：JSON 格式错误

```
❌ 错误：stat_effects = "{speed: 0}"（缺少引号）
✅ 正确：stat_effects = "{\"speed\": 0}"

❌ 错误：effect_data = "{type: apply_condition}"（缺少引号）
✅ 正确：effect_data = "{\"type\": \"apply_condition\"}"
```

**原因**：CSV 中的 JSON 必须用转义引号。

## 六、快速排查表

| 症状 | 可能原因 | 检查项 |
|---|---|---|
| CSV 解析报错 | 逗号未包裹 | 文本中的逗号是否用双引号包裹 |
| 数值字段报错 | 混入了文本 | 检查是否有"尺"、"金币"等单位 |
| 引用找不到 | ID 错误 | 检查引用的 ID 是否存在于目标表 |
| 范围框显示错误 | 目标类型错误 | 检查 target_type 是否正确 |
| 伤害计算错误 | 骰娘格式错误 | 检查 dice_interaction 格式 |
| 状态不生效 | JSON 格式错误 | 检查 stat_effects/effect_data 的 JSON |
| DLC 加载失败 | manifest 错误 | 检查 manifest.json 格式和依赖 |
