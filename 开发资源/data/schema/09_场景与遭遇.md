# 09_场景与遭遇表 (scenes & encounters)

## 用途

描述冒险故事中的场景和战斗遭遇。供以下模块使用：
- **故事编辑器**：模组作者构建故事地图
- **战斗模块**：加载场景地图和敌方单位
- **AI DM**：理解场景布局，生成叙事描述

## 说明

这是**故事数据**，和**规则数据**（种族/职业/法术）分开。
规则数据是"游戏有什么"，故事数据是"这个故事里有什么"。

## 场景表 (scenes)

### 表结构

| 列名 | 英文名 | 类型 | 必填 | 默认值 | 说明 | 示例 |
|---|---|---|---|---|---|---|
| id | id | int | 是 | - | 唯一标识 | 1 |
| 模组ID | module_id | int | 是 | - | 所属模组 | 1 |
| 名字 | name | string | 是 | - | 场景名称 | 地精营地入口 |
| 描述 | desc | string | 是 | - | 场景描述文本 | "你们来到一片密林中的空地..." |
| 底图 | background_image | string | 否 | - | 底图文件路径 | "scenes/forest_clearing.jpg" |
| 格子尺寸 | grid_size | int | 是 | 5 | 每格代表多少英尺 | 5 |
| 地图宽度 | map_width | int | 是 | - | 地图宽度（格子数） | 20 |
| 地图高度 | map_height | int | 是 | - | 地图高度（格子数） | 15 |
| 地形数据 | terrain_data | string | 否 | - | 地形信息，见下方格式 | - |
| 连接场景 | connected_scenes | string | 否 | - | 可通往的其他场景 ID | "2,3" |
| 初始遭遇 | initial_encounter | int | 否 | - | 进入场景时触发的遭遇 | 1 |
| 可交互物件 | interactables | string | 否 | - | 场景中的可交互物件 | 见下方格式 |
| DLC | dlc | string | 是 | phb | 所属 DLC | dlc_04 |

### 地形数据格式 (terrain_data)

描述场景中每个格子的地形类型：

```json
{
  "default": "grass",           // 默认地形
  "cells": [                     // 特殊地形格子
    {"x": 5, "y": 3, "type": "tree", "blocks_movement": true, "blocks_vision": true},
    {"x": 6, "y": 3, "type": "tree", "blocks_movement": true, "blocks_vision": true},
    {"x": 10, "y": 8, "type": "water", "difficult_terrain": true, "blocks_movement": false},
    {"x": 10, "y": 9, "type": "water", "difficult_terrain": true, "blocks_movement": false}
  ]
}
```

地形类型：

| type | 说明 | 属性 |
|---|---|---|
| grass | 草地 | 无特殊 |
| dirt | 泥土 | 无特殊 |
| stone | 石板 | 无特殊 |
| tree | 树木 | blocks_movement=true, blocks_vision=true |
| rock | 岩石 | blocks_movement=true |
| water | 水域 | difficult_terrain=true |
| mud | 沼泽 | difficult_terrain=true |
| pit | 陷阱 | 特殊，见 interactables |
| door | 门 | blocks_movement=true，可交互 |
| stairs | 楼梯 | 连接不同层级 |

### 可交互物件格式 (interactables)

```json
[
  {
    "id": "chest_01",
    "name": "上锁的箱子",
    "x": 8,
    "y": 5,
    "type": "container",
    "requires_check": {"skill": 20, "dc": 15},  // 需要巧手检定 DC15
    "contents": [{"item_id": 1001, "quantity": 50}]  // 50gp
  },
  {
    "id": "lever_01",
    "name": "拉杆",
    "x": 12,
    "y": 10,
    "type": "switch",
    "effect": "open_door:door_01"
  }
]
```

## 与战斗模块的交互

1. 玩家进入场景 → 检查 `initial_encounter`
2. 如果有遭遇 → 加载场景地图（底图 + 格子 + 地形）
3. 根据 `enemies` 生成敌方单位，放置在 `positions`
4. 玩家布置己方单位（或预设位置）
5. 开始战斗：先攻排序 → 回合制战斗
6. 检查 `victory_condition` / `defeat_condition`
7. 战斗结束 → 执行 `post_battle` → 可能切换回 AI DM 叙事模式
