# 14_工具表 (tools)

## 用途

描述角色可熟练使用的工具、乐器、赌具和其他工具。供以下模块使用：
- **车卡模块**：选择工具熟练项，影响制作能力
- **AI DM**：判断角色是否具备特定工具使用能力

## 依赖

| 表名 | 用途 |
|---|---|
| 字典表 | `type`（工具分类）、`attr`（关联属性）引用值 |

## 版本状态

| 字段 | 状态 | 说明 |
|---|---|---|
| 全部字段 | ✅ v0.1 | 车卡功能已使用 |

## 表结构

| 列名 | 英文名 | 类型 | 必填 | 状态 | 默认值 | 说明 | 示例 | 常见错误 |
|---|---|---|---|---|---|---|---|---|
| id | id | int | 是 | ✅ | - | 唯一标识 | 1 | - |
| 名字 | name | string | 是 | ✅ | - | 中文工具名 | 炼金工具 | - |
| 价格 | cost | int | 否 | ✅ | - | 购买价格（金币） | 50 | - |
| 类型 | type | int | 是 | ✅ | - | 工具分类 ID | 66（工匠） | 写"工匠"而不是 66 |
| 属性 | attr | int | 否 | ✅ | - | 关联属性 ID | 11（智力） | - |
| 重量 | weight | int | 否 | ✅ | - | 重量（磅） | 8 | - |
| 重量单位 | weight_unit | string | 否 | ✅ | - | 重量单位 | lb | - |
| 操作 | operation | string | 否 | ✅ | - | 工具能力和 DC 描述 | 辨析一种物质（DC15） | - |
| 制作 | craft | string | 否 | ✅ | - | 可以制作哪些物品 | 强酸、炽火胶、材料包 | - |
| DLC | dlc | string | 是 | ✅ | phb | 所属 DLC 标识 | phb | - |

## 枚举值列表

### 工具分类枚举 (type)

| 值 | 含义 | 说明 |
|---|---|---|
| 66 | 工匠工具 | 炼金、铁匠、木匠等制作类工具 |
| 67 | 乐器 | 笛子、鲁特琴等表演类工具 |
| 68 | 赌具 | 骰子、纸牌等赌博类工具 |
| 69 | 其他工具 | 草药工具、导航工具等其他类 |
