# 04_法术表 (spells)

## 用途

描述角色可施展的法术。供以下模块使用：
- **车卡模块**：选择已知/准备法术
- **战斗模块**：施法时计算范围、伤害、状态效果
- **AI DM**：理解法术效果，生成叙事描述

## 依赖

| 表名 | 用途 |
|---|---|
| 字典表 | 学派(id)、伤害类型、法术成分类型 |
| 职业表 | 验证 `职业` 字段的 ID 是否有效 |
| 状态效果表 | `效果类型` = debuff/control 时，引用具体状态 |

## 版本状态

| 字段 | 状态 | 说明 |
|---|---|---|
| 基础字段（id~详情） | ✅ v0.1 | 车卡功能已使用 |
| 战斗字段（目标类型~效果类型） | ⏳ v0.2 | 战斗模块开发中 |
| AI字段（AI规则） | ⏳ v0.2 | AI DM 开发中 |

## 目标类型决策树（AI 填写时必看）

这是**最重要**的字段，直接决定战斗模块如何渲染范围框。

```
法术需要选择目标？
  ├─ 否 → 影响施法者自身？
  │     ├─ 是 → target_type = self
  │     └─ 否 → 影响一个固定点/区域？
  │           ├─ 是 → 判断形状：
  │           │     ├─ 球形扩散 → target_type = sphere
  │           │     ├─ 锥形扩散 → target_type = cone
  │           │     ├─ 直线 → target_type = line
  │           │     ├─ 立方体 → target_type = cube
  │           │     ├─ 圆柱 → target_type = cylinder
  │           │     └─ 墙壁 → target_type = wall
  │           └─ 否 → 特殊效果 → target_type = special
  │
  └─ 是 → 需要触碰？
        ├─ 是 → target_type = touch
        └─ 否 → 影响单个生物/物件？
              ├─ 是 → target_type = single
              └─ 否 → 影响多个目标？
                    ├─ 是 → target_type = multiple
                    └─ 否 → 以自身为中心的区域？
                          ├─ 是 → target_type = self_radius
                          └─ 否 → target_type = special
```

## 目标尺寸与格子换算

战斗模块使用**六边形格子**，但数据以**英尺**存储。

前端根据用户设置的"每格英尺数"自动换算：

```
覆盖格子数 = ceil(目标尺寸 / 每格英尺数)

示例：
- 火球术 target_size=20
- 用户设置每格 = 5ft
- 覆盖格子数 = ceil(20/5) = 4 格半径
- 用户设置每格 = 10ft
- 覆盖格子数 = ceil(20/10) = 2 格半径
```

## 升环格式

```
格式：level:[触发条件],[效果]

示例：
"level:+1,+1d6"           → 每升一环，伤害+1d6
"level:3,+1目标"           → 3环时多1个目标
"level:5,11,17,2d6,3d6,4d6" → 5/11/17级时伤害骰变化
```

---

## 骰娘格式

```
格式：基础骰,升级骰1,升级骰2,...

示例：
"1d6,5d6,3d6,4d6"  → 1级1d6，5级2d6，11级3d6，17级4d6
"1d8,2d8,3d8,4d8"  → 同上模式
"1d10*1,*1（2,3,4）" → 1级1发，5级2发，11级3发，17级4发
```

## AI规则格式

这是给 AI DM 看的结构化描述，帮助 AI 理解法术在叙事中如何表现。

```
格式：目标：[描述]。判定：[判定方式]。效果：[效果描述]。特殊：[额外说明]。

示例（火球术）：
"目标：施法距离内一点，20尺半径球状区域。判定：范围内每名生物敏捷豁免，失败受全额伤害，成功半伤。效果：8d6火焰伤害，可点燃无主易燃物。特殊：升环每环+1d6。"

示例（祝福术）：
"目标：至多3个30尺内可见生物。效果：持续1分钟，目标攻击检定和豁免检定+1d4。特殊：需专注，升环每环多1目标。"
```

## 常见错误

| 错误 | 正确 | 说明 |
|---|---|---|
| 职业写 "法师,术士" | 职业写 "10,12" | 用 ID，不用名字 |
| 目标类型写 "球状" | 目标类型写 "sphere" | 用英文枚举值 |
| 施法时间写 "1动作" | 施法时间写 "action" | 用标准枚举值 |
| 伤害类型写 "火焰" | 伤害类型写 "fire" | 用字典表英文键 |
| 目标尺寸写 "20尺" | 目标尺寸写 "20" | 纯数字，单位固定为英尺 |
| 材料价值写 "25金币" | 材料价值写 "25gp" | 用 gp/sp/cp 单位 |
| 详情里写 "8d6火焰伤害" | 详情写完整描述 | 详情是完整文本，不是摘要 |
| 升环写 "每高一环+1d6" | 升环写 "level:+1,+1d6" | 用标准格式 |

## 战斗模块使用说明

当玩家在战斗中选择施法时，战斗模块读取法术数据的流程：

1. 读取 `target_type` → 决定渲染什么形状的范围框
2. 读取 `target_size` → 决定范围框的大小（根据当前格子缩放比例换算）
3. 玩家拖动/旋转范围框到满意位置 → 程序计算覆盖哪些格子
4. 读取 `effect_type` → 决定结算逻辑（伤害/治疗/状态）
5. 读取 `save_type` → 决定目标进行什么豁免
6. 读取 `save_success` → 决定豁免成功后的效果
7. 读取 `dice_interaction` → 计算伤害/治疗数值
8. 如有 `upcast` → 询问玩家使用几环法术位，调整效果
9. 如有 `concentration=1` → 检查玩家是否已专注其他法术
10. 执行效果，更新战斗状态
