# 03_专长表 (feats)

## 用途

描述角色可获取的专长。供以下模块使用：
- **车卡模块**：升级时选择专长，应用属性加成和专长效果
- **战斗模块**：战斗风格专长影响战斗计算
- **AI DM**：生成角色时自动推荐专长

## 依赖

| 表名 | 用途 |
|---|---|
| 字典表 | `type`（专长类型）引用值 |
| 引用表 | `rules` 中的自描述表达式可能引用其他表的数据 |

## 版本状态

| 字段 | 状态 | 说明 |
|---|---|---|
| 基础字段（id~name） | ✅ v0.1 | 车卡功能已使用 |
| 类型（type） | ✅ v0.1 | 起源/通用/战斗风格/传奇恩惠 分类 |
| 先决条件（prerequisite） | ✅ v0.1 | 升级时的前置校验 |
| 属性加成（attr） | ✅ v0.1 | 选择专长时增加属性值 |
| 规则表达式（rules） | ✅ v0.1 | 自描述表达式，已替代旧 link() 格式 |

## 表结构

| 列名 | 英文名 | 类型 | 必填 | 状态 | 默认值 | 说明 | 示例 | 常见错误 |
|---|---|---|---|---|---|---|---|---|
| id | id | int | 是 | ✅ | - | 唯一标识 | 1 | - |
| 名字 | name | string | 是 | ✅ | - | 中文专长名 | 警戒 | - |
| 类型 | type | int | 是 | ✅ | - | 专长类型，见下方枚举 | 42（起源专长） | 写"起源专长"而不是 42 |
| 特性chain: | chain | string | 否 | ✅ | - | 连锁引用其他特性的 ID | - | - |
| 属性 | attr | string | 否 | ✅ | - | 属性加成表达式 | ability(4)+1 | 格式错误导致属性不增加 |
| 先决 | prerequisite | string | 否 | ✅ | - | 前置条件表达式 | lv>=4 | 语法错误导致校验失败 |
| 骰娘互动 | dice | string | 否 | ✅ | - | 骰娘机器人指令 | - | - |
| 车卡数据 | rules | string | 否 | ✅ | - | **自描述表达式**（v1.0 替代 link()） | feats(type=44)+1 | 仍使用旧 link(id) 格式 |
| 代码 | code | string | 否 | ✅ | - | 代码标记（如 choose） | - | - |
| DLC | dlc | string | 是 | ✅ | phb | 所属 DLC 标识 | phb | - |
| 详情 | desc | string | 是 | ✅ | - | 专长完整描述文本 | - | - |

## 枚举值列表

### 专长类型枚举 (type)

| 值 | 含义 | 获取方式 |
|---|---|---|
| 42 | 起源专长 | 1级角色创建时从背景获得 |
| 43 | 通用专长 | 4/8/12/16/19 级选择 |
| 44 | 战斗风格专长 | 战士等职业特性给予 |
| 45 | 传奇恩惠专长 | 20 级传奇恩惠 |

### 属性加成格式 (attr)

| 格式 | 含义 | 示例 |
|---|---|---|
| ability(N)+M | 属性 N 增加 M 点 | ability(4)+1（敏捷+1） |
| ability(N)+Mability(K)+L | 多属性增加 | ability(1)+1ability(9)+1（力量+1和体质+1） |
