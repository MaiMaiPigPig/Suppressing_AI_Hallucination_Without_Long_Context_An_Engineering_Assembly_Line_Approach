# 08_怪物表 (monsters)

## 用途

描述战斗中可能遇到的怪物/NPC。供以下模块使用：
- **战斗模块**：敌方单位的数据、AI 行为
- **故事编辑器**：模组作者放置怪物到场景中
- **AI DM**：生成叙事描述，控制怪物行为

## 依赖

| 表名 | 用途 |
|---|---|
| 字典表 | 生物类型、体型、阵营 |
| 状态效果表 | 怪物免疫/抗性对应的状态 |
| 法术表 | 怪物施法能力 |
| 战斗动作表 | 怪物的特殊动作 |

## 版本状态

| 字段 | 状态 | 说明 |
|---|---|---|
| 基础字段（id~详情） | ⏳ v0.2 | 战斗模块开发中 |
| AI行为 | 📋 v0.3 | 等 AI 队友开发 |
| 传奇动作/巢穴动作 | 📋 v0.3 | 等高级怪物开发 |

## 特殊速度格式 (special_speed)

```
格式：类型:速度（英尺）

示例：
"fly:30"        → 飞行速度 30 尺
"swim:40"       → 游泳速度 40 尺
"burrow:20"     → 掘穴速度 20 尺
"climb:30"      → 攀爬速度 30 尺
"hover:30"      → 悬浮 30 尺（不会摔落）
```

多个速度用逗号分隔：
```
"fly:30,swim:40"  → 飞行 30 尺，游泳 40 尺
```

---

## 感官格式 (senses)

```
格式：类型:范围（英尺）

示例：
"darkvision:60"     → 黑暗视觉 60 尺
"blindsight:10"     → 盲视 10 尺
"tremorsense:30"    → 震颤感知 30 尺
"truesight:120"     → 真实视觉 120 尺
```

多个感官用逗号分隔：
```
"darkvision:60,blindsight:10"  → 黑暗视觉 60 尺，盲视 10 尺
```

## 施法格式 (spellcasting)

```json
{
  "ability": "int",
  "level": 3,
  "slots": [4, 2],
  "spells": [
    {"level": 0, "ids": [1, 8]},
    {"level": 1, "ids": [35, 49]},
    {"level": 2, "ids": [55]}
  ]
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| ability | string | 是 | 施法属性：str/dex/con/int/wis/cha |
| level | int | 是 | 施法者等级 |
| slots | array | 是 | 法术位数量，索引=环阶-1 |
| spells | array | 是 | 已知/准备法术 |

## AI行为格式 (ai_behavior)

描述 AI 控制此怪物时的决策策略：

```json
{
  "priority": "aggressive",
  "target_selection": "weakest",
  "tactics": [
    {
      "condition": "hp_above:0.5",
      "action": "attack_melee",
      "weight": 3
    },
    {
      "condition": "hp_below:0.3",
      "action": "retreat",
      "weight": 5
    },
    {
      "condition": "ally_adjacent",
      "action": "flank",
      "weight": 2
    }
  ],
  "spell_priority": [
    {"spell_id": 49, "condition": "ally_injured", "target": "ally"},
    {"spell_id": 8, "condition": "always", "target": "enemy"}
  ]
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| priority | string | 是 | 整体策略，见上方枚举 |
| target_selection | string | 是 | 目标选择策略，见上方枚举 |
| tactics | array | 是 | 战术列表 |
| tactics.condition | string | 是 | 触发条件 |
| tactics.action | string | 是 | 执行的动作 |
| tactics.weight | int | 是 | 权重（越高越优先） |
| spell_priority | array | 否 | 施法优先级（如果有施法能力） |
| spell_priority.spell_id | int | 是 | 法术 ID |
| spell_priority.condition | string | 是 | 施法条件 |
| spell_priority.target | string | 是 | 目标类型：ally/enemy/self |

### 条件表达式 (tactics.condition)

| 表达式 | 含义 |
|---|---|
| always | 总是适用 |
| hp_above:X | 生命值高于 X% |
| hp_below:X | 生命值低于 X% |
| ally_injured | 盟友受伤 |
| ally_adjacent | 盟友相邻 |
| enemy_adjacent | 敌人相邻 |
| outnumbered | 数量劣势 |
| outnumbering | 数量优势 |
| spell_slot_available:N | 有 N 环法术位可用 |
| condition:XXX | 处于 XXX 状态 |
| not_condition:XXX | 不处于 XXX 状态 |
| round_above:N | 第 N 轮之后 |
| round_below:N | 第 N 轮之前 |

## 与战斗模块的交互

1. 遭遇开始时，引擎从怪物表读取数据生成敌方单位
2. 每个怪物单位继承怪物的属性、动作、AI 行为
3. AI 回合时，读取 `ai_behavior` 决定行动
4. 玩家回合时，显示可用动作菜单
5. 状态效果按 `condition_immunities` 判断是否免疫
6. 伤害按 `damage_immunities/resistances/vulnerabilities` 计算
