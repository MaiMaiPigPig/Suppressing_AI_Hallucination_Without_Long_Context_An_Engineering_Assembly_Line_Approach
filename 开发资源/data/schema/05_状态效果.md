# 05_状态效果表 (conditions)

## 用途

描述战斗中角色可能获得的各种状态效果。供以下模块使用：
- **战斗模块**：应用/移除状态，计算状态对属性的影响
- **车卡模块**：显示角色免疫/抗性相关特性
- **AI DM**：理解角色当前状态，生成叙事描述
- **字典表/查询手册**：玩家在网页右上角查询状态含义

## 依赖

## 枚举值列表

### 状态分类枚举 (category)

| 值 | 英文名 | 中文名 | 包含状态 |
|---|---|---|---|
| 1 | mental | 心智 | 魅惑、恐慌、昏迷 |
| 2 | physical | 身体 | 束缚、倒地、麻痹、石化、擒抱 |
| 3 | sensory | 感官 | 目盲、耳聋、隐形 |
| 4 | magical | 魔法 | 法术造成的特殊状态 |
| 5 | environmental | 环境 | 由地形/环境造成 |
| 6 | poison | 毒素 | 中毒 |
| 7 | disease | 疾病 | 疾病状态 |

### 持续时间类型枚举 (duration_type)

| 值 | 含义 | duration_value | 示例 |
|---|---|---|---|
| instant | 瞬时，立即生效无持续 | 留空 | - |
| round | 持续 N 轮 | 轮数 | 1 = 到施法者下回合结束 |
| minute | 持续 N 分钟 | 分钟数 | 1 = 1分钟 |
| hour | 持续 N 小时 | 小时数 | 1 = 1小时 |
| day | 持续 N 天 | 天数 | 1 = 1天 |
| permanent | 永久，直到特定条件解除 | 留空 | - |
| long_rest | 直到完成长休 | 留空 | - |
| short_rest | 直到完成短休 | 留空 | - |
| concentration | 只要专注就持续 | 留空 | 关联法术的专注状态 |
| special | 特殊规则，看 auto_remove | 留空 | - |

### 叠加规则枚举 (stack_rule)

当 `stackable=1` 时，使用以下规则：

| 值 | 含义 | 示例 |
|---|---|---|
| max | 取最高值，不叠加 | 多个加速术，只取最高速度加成 |
| sum | 数值相加 | 多个临时生命值叠加 |
| replace | 后覆盖前 | 新的替代旧的 |
| duration | 延长持续时间 | 刷新持续时间 |

### 自动解除条件枚举 (auto_remove)

| 值 | 含义 | 示例状态 |
|---|---|---|
| damage | 受到伤害时解除 | 专注法术、睡眠 |
| attack_caster | 攻击施法者时解除 | 魅惑（某些版本） |
| save_success | 豁免成功时解除 | 大部分持续状态 |
| action | 消耗动作解除 | 自己挣脱束缚 |
| bonus_action | 消耗附赠动作解除 | - |
| reaction | 消耗反应解除 | - |
| ally_action | 盟友帮助解除 | 倒地（盟友扶起） |
| spell_end | 法术结束时解除 | 法术造成的临时状态 |
| long_rest | 长休后解除 | 某些疲劳 |
| custom | 自定义，看详情描述 | 特殊情况 |

### 属性影响类型枚举 (stat_effects.type)

| 值 | 含义 | 示例 |
|---|---|---|
| set | 设置为固定值 | speed=0（无法移动） |
| bonus | 加值（可为负） | ac=-2 |
| advantage | 优势 | attack_roll=true |
| disadvantage | 劣势 | saving_throw=true |
| half | 减半（向下取整） | speed=0.5 |
| immunity | 免疫某种伤害 | damage_type="fire" |
| resistance | 抗性 | damage_type="cold" |
| vulnerability | 易伤 | damage_type="lightning" |

### 动作影响枚举 (action_effects)

| 值 | 含义 | 示例状态 |
|---|---|---|
| cant_move | 无法移动 | 束缚、麻痹 |
| cant_take_action | 无法执行动作 | 失能、石化 |
| cant_take_bonus_action | 无法执行附赠动作 | 某些特殊状态 |
| cant_take_reaction | 无法执行反应 | 惊讶、某些状态 |
| cant_attack | 无法攻击 | 魅惑（某些版本） |
| cant_attack_caster | 无法攻击施法者 | 魅惑 |
| cant_cast_spell | 无法施法 | 沉默 |
| cant_concentrate | 无法专注 | - |
| must_move_away | 必须远离某目标 | 恐慌 |
| must_move_toward | 必须接近某目标 | - |
| only_crawl | 只能爬行 | 倒地 |
| drop_prone | 陷入倒地 | 某些击退效果 |
| auto_fail_dex_save | 敏捷豁免自动失败 | 麻痹、石化 |
| auto_fail_str_save | 力量豁免自动失败 | 石化 |

多个限制用英文逗号分隔：
```
cant_move,cant_take_action,cant_take_reaction
```

### 检定影响枚举 (check_effects)

| 值 | 含义 | 示例状态 |
|---|---|---|
| attack_advantage | 攻击检定优势 | 隐形、优势来源 |
| attack_disadvantage | 攻击检定劣势 | 中毒、劣势来源 |
| save_advantage | 豁免检定优势 | 某些祝福 |
| save_disadvantage | 豁免检定劣势 | 恐慌 |
| ability_check_advantage | 属性检定优势 | 某些增益 |
| ability_check_disadvantage | 属性检定劣势 | 疲惫 |
| init_advantage | 先攻优势 | 某些特性 |
| init_disadvantage | 先攻劣势 | - |
| auto_fail_str_dex | 力量和敏捷检定自动失败 | 石化 |
| perception_disadvantage | 感知检定劣势 | 目盲 |
| stealth_advantage | 隐匿检定优势 | 隐形 |

## 属性影响格式 (stat_effects)

JSON 格式，描述状态如何改变角色属性：

```json
{
  "speed": {"type": "set", "value": 0},
  "ac": {"type": "bonus", "value": -2},
  "attack_roll": {"type": "advantage", "value": true},
  "saving_throw": {"type": "disadvantage", "value": true}
}
```

| type | 含义 | 示例 |
|---|---|---|
| set | 设置为固定值 | speed=0（无法移动） |
| bonus | 加值（可为负） | ac=-2 |
| advantage | 优势 | attack_roll=true |
| disadvantage | 劣势 | saving_throw=true |
| half | 减半（向下取整） | speed=0.5 |
| immunity | 免疫某种伤害 | damage_type="fire" |
| resistance | 抗性 | damage_type="cold" |
| vulnerability | 易伤 | damage_type="lightning" |

## 常见错误

| 错误 | 正确 | 说明 |
|---|---|---|
| 持续时间写 "1分钟" | 持续时间类型写 "minute"，数值写 "1" | 分开两个字段 |
| stat_effects 写文本 | stat_effects 写 JSON | 必须是机器可解析的格式 |
| action_effects 写 "不能攻击" | action_effects 写 "cant_attack" | 用标准枚举值 |
| 免疫来源写 "精灵" | 免疫来源写 "elf_ancestry" | 用特性英文名 |
| 颜色写 "红色" | 颜色写 "#ff0000" | 用 hex 格式 |

## 与字典表的关联

状态效果表需要以下字典表条目：

```
字典表新增：
- 状态分类 (Condition Categories)
  - 1: 心智 (Mental) - 魅惑、恐慌等
  - 2: 身体 (Physical) - 束缚、倒地等
  - 3: 感官 (Sensory) - 目盲、耳聋等
  - 4: 魔法 (Magical) - 法术造成的特殊状态
  - 5: 环境 (Environmental) - 由地形/环境造成
  - 6: 毒素 (Poison) - 中毒
  - 7: 疾病 (Disease) - 疾病状态
```
