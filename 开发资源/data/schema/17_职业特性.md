# 17_职业特性表 (class_features)

## 用途

描述各职业在升级时获得的特性。供以下模块使用：
- **车卡模块**：角色升级时自动获得对应等级的职业特性
- **战斗模块**：战斗相关特性（如狂暴、额外攻击）影响战斗计算
- **AI DM**：理解特性效果，生成叙事描述

## 依赖

| 表名 | 用途 |
|---|---|
| 职业表 | `class` 字段引用职业 ID |
| 字典表 | `subclass` 引用子职 ID |
| 引用表 | `rules` 中的自描述表达式可能引用其他表 |

### rules 字段说明（自描述表达式）

这是 v1.0 最重要的变更——所有 `link(id)` 已替换为自描述表达式。详见 `10_自描述表达式规范.md`。

常见类型：
- 基本引用：`feats(id=5)` — 引用 ID=5 的专长
- 筛选：`spells(class=4,lv=0)+2` — 德鲁伊戏法选2个
- 选择：`choose(skills(1,2,3))+2` — 从列表中选2个技能
- 公式：`ac=10+AbilityModifiers(4)+AbilityModifiers(9)` — AC 计算
- 范围：`growup(303→322)` — 范围数据引用
