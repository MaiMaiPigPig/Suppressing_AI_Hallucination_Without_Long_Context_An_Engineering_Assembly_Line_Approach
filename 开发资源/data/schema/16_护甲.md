# 16_护甲表 (armors)

## 用途

描述角色可穿戴的护甲。供以下模块使用：
- **车卡模块**：选择护甲熟练项，装备护甲时计算 AC
- **战斗模块**：AC 计算公式应用于战斗防御

## 依赖

| 表名 | 用途 |
|---|---|
| 字典表 | `armor`（护甲分类）引用值 |

## 版本状态

| 字段 | 状态 | 说明 |
|---|---|---|
| 全部字段 | ✅ v0.1 | 车卡/战斗功能已完整使用 |

## 表结构

| 列名 | 英文名 | 类型 | 必填 | 状态 | 默认值 | 说明 | 示例 | 常见错误 |
|---|---|---|---|---|---|---|---|---|
| id | id | int | 是 | ✅ | - | 唯一标识 | 1 | - |
| 名字 | name | string | 是 | ✅ | - | 中文护甲名 | 布甲 | - |
| 英文名 | name_en | string | 否 | ✅ | - | 英文护甲名 | Padded Armor | - |
| 护甲等级（AC） | ac | string | 是 | ✅ | - | AC 计算公式（自描述表达式） | 11+AbilityModifiers(4) | 直接写数字而不是公式 |
| 力量 | strength | string | 否 | ✅ | - | 力量要求（有则显示，无则留空） | 13 | - |
| 隐匿 | stealth | string | 否 | ✅ | - | 隐匿影响：空=无影响，disadvantage=劣势 | disadvantage | 写"劣势"而不是 disadvantage |
| 重量 | weight | int | 否 | ✅ | - | 重量（磅） | 8 | - |
| 重量单位 | weight_unit | string | 否 | ✅ | - | 重量单位 | - | - |
| 价格 | cost | string | 否 | ✅ | - | 购买价格 | 5GP | 格式：数字+货币代码 |
| 甲类型 | armor | int | 是 | ✅ | - | 2=轻甲, 3=中甲, 4=重甲, 5=盾牌 | 2 | 写"轻甲"而不是 2 |
| DLC | dlc | string | 是 | ✅ | phb | 所属 DLC 标识 | phb | - |

## 枚举值列表

### 护甲分类枚举 (armor)

| 值 | 含义 | 特点 |
|---|---|---|
| 2 | 轻甲 | AC=护甲基础+敏捷加值全额 |
| 3 | 中甲 | AC=护甲基础+敏捷加值（上限+2） |
| 4 | 重甲 | AC=固定值，不加入敏捷加值；可能有力量要求 |
| 5 | 盾牌 | AC=额外+2；需要一只手持有 |

### 隐匿影响 (stealth)

| 值 | 含义 |
|---|---|
| （空） | 无隐匿劣势 |
| disadvantage | 隐匿检定有劣势 |

### AC 计算公式格式 (ac)

| 格式 | 含义 | 示例 |
|---|---|---|
| N+AbilityModifiers(M) | AC = N + 属性M的调整值 | 11+AbilityModifiers(4) → AC=11+敏捷调整 |
| N | 固定AC值 | 18（板甲固定 AC=18） |

### 价格格式 (cost)

| 格式 | 示例 |
|---|---|
| 数字+货币代码 | 5GP（5金币）、1 SP（1银币） |
