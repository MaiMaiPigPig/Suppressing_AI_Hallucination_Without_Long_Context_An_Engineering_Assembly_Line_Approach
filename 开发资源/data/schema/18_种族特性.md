# 18_种族特性表 (race_features)

## 用途

描述各种族的内在特性。供以下模块使用：
- **车卡模块**：创建角色选择种族后，自动获得种族特性
- **战斗模块**：种族特性（如抗性、特殊能力）影响战斗计算
- **AI DM**：理解种族特性效果

## 依赖

| 表名 | 用途 |
|---|---|
| 种族表 | `choice` 字段的种族 ID 引用 |
| 引用表 | `rules` 中的自描述表达式可能引用其他表 |

## 版本状态

| 字段 | 状态 | 说明 |
|---|---|---|
| 基础字段（id~name） | ✅ v0.1 | 车卡功能已使用 |
| 选择（choice） | ✅ v0.1 | 子种族或变体选择规则 |
| 规则表达式（rules） | ✅ v0.1 | 自描述表达式（v1.0） |

## 表结构

| 列名 | 英文名 | 类型 | 必填 | 状态 | 默认值 | 说明 | 示例 | 常见错误 |
|---|---|---|---|---|---|---|---|---|
| id | id | int | 是 | ✅ | - | 唯一标识 | 1 | - |
| 名字 | name | string | 是 | ✅ | - | 中文特性名 | 天界抗性 | - |

## 枚举值列表

### choice 字段说明

`choice` 字段表示需要用户从子种族中选择。常见值：

| 值 | 含义 |
|---|---|
| 12 | 标准子种族选择（人类/精灵等） |
| 其他 | 特定种族的变体选择规则 |

### rules 字段说明（自描述表达式）

同职业特性表中的 rules 格式。详见 `10_自描述表达式规范.md`。

种族特性中常见表达式：
- `spells(class=4,lv=0)+1` — 选择一个特定职业的戏法
- `link(293)` — **旧格式，v1.0 已废弃**（存量数据待迁移）
