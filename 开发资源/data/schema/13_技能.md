# 13_技能表 (skills)

## 用途

描述角色可熟练的技能清单。供以下模块使用：
- **车卡模块**：选择技能熟练项，计算技能加值
- **战斗模块**：技能检定（如察觉、隐匿、运动等）
- **AI DM**：判断角色是否具备特定技能

## 依赖

| 表名 | 用途 |
|---|---|
| 字典表 | `type`（技能分类）、`attr`（关联属性）引用值 |

## 版本状态

| 字段 | 状态 | 说明 |
|---|---|---|
| 全部字段 | ✅ v0.1 | 车卡功能已完整使用 |

## 表结构

| 列名 | 英文名 | 类型 | 必填 | 状态 | 默认值 | 说明 | 示例 | 常见错误 |
|---|---|---|---|---|---|---|---|---|
| id | id | int | 是 | ✅ | - | 唯一标识 | 1 | - |
| 名字 | name | string | 是 | ✅ | - | 中文技能名 | 力量 | - |
| 类型 | type | int | 是 | ✅ | - | 技能分类 ID | 1（力量技能） | 写"力量"而不是 1 |
| 属性 | attr | string | 是 | ✅ | - | 关联的英文属性名 | strength | 写"力量"而不是 strength |
| 英文名 | name_en | string | 否 | ✅ | - | 英文技能名 | Strength | - |
| 详情 | desc | string | 否 | ✅ | - | 技能描述文本 | 力气 | - |
