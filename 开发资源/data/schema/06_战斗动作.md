# 06_战斗动作表 (combat_actions)

## 用途

描述战斗中角色可以执行的所有动作类型。供以下模块使用：
- **战斗模块**：构建动作菜单，校验动作合法性
- **AI DM/AI 队友**：决定 AI 角色每回合做什么
- **车卡模块**：显示角色可用的特殊动作

## 说明

DND 战斗系统有标准的动作经济：
- **动作 (Action)**：每回合 1 个（攻击、施法、疾走等）
- **附赠动作 (Bonus Action)**：每回合最多 1 个
- **反应 (Reaction)**：每回合 1 次（借机攻击、某些法术）
- **移动 (Movement)**：移动速度范围内，可分多次使用
- **交互 (Interaction)**：免费，每回合 1 次（拔武器、开门等）

本表记录所有**非通用**的动作（通用动作如"移动"不需要记录）。
特性、法术、装备可能赋予角色特殊的动作选项。

## 依赖

| 表名 | 用途 |
|---|---|
| 职业特性表 | 特性赋予的特殊动作 |
| 法术表 | 法术赋予的特殊动作 |
| 状态效果表 | 某些状态下限制/改变可用动作 |

## 枚举值列表

### 动作类型枚举 (action_type)

| 值 | 含义 | 每回合限制 |
|---|---|---|
| action | 标准动作 | 1 个 |
| bonus_action | 附赠动作 | 最多 1 个 |
| reaction | 反应 | 1 次（特定触发条件） |
| free_action | 免费动作 | 无限制 |
| movement | 移动（特殊移动方式） | 消耗移动力 |
| interaction | 交互 | 1 次（免费） |
| special | 特殊（看具体规则） | 视情况而定 |

### 来源类型枚举 (source_type)

| 值 | 含义 | source_id 指向 |
|---|---|---|
| class_feature | 职业特性 | 职业特性表 |
| race_feature | 种族特性 | 种族特性表 |
| feat | 专长 | 专长表 |
| spell | 法术 | 法术表 |
| item | 物品/装备 | 装备表 |
| condition | 状态效果 | 状态效果表 |
| basic | 基础规则 | 0（无具体来源） |

### 恢复条件枚举 (recharge)

| 值 | 含义 |
|---|---|
| short_rest | 短休后恢复 |
| long_rest | 长休后恢复 |
| round | 每轮恢复 |
| turn | 每回合恢复 |
| dawn | 黎明时恢复 |
| never | 不恢复（一次性） |
| custom | 自定义，看详情描述 |

### 效果类型枚举 (effect_data.type)

| 值 | 说明 | 示例 |
|---|---|---|
| apply_condition | 给目标施加状态 | 狂暴 → 给自己加 rage 状态 |
| remove_condition | 移除目标状态 | 镇定 → 移除恐慌 |
| deal_damage | 造成伤害 | 攻击动作 |
| heal | 恢复生命 | 治疗动作 |
| move | 特殊移动 | 传送、飞行 |
| cast_spell | 施法 | 法术动作 |
| use_item | 使用物品 | 喝药水 |
| dash | 疾走（移动速度翻倍） | 疾走动作 |
| disengage | 撤离（不引发借机攻击） | 撤离动作 |
| dodge | 闪避 | 闪避动作 |
| help | 协助 | 协助动作 |
| hide | 躲藏 | 躲藏动作 |
| search | 搜索 | 搜索动作 |
| ready | 预备 | 预备动作 |
| grapple | 擒抱 | 擒抱动作 |
| shove | 推撞 | 推撞动作 |

## 消耗资源格式 (cost)

```
格式：资源类型:数量

示例：
"rage_charge:1"          → 消耗1点狂暴次数
"ki_point:2"             → 消耗2点气
"sorcery_point:3"        → 消耗3点术法点
"spell_slot:1"           → 消耗1环法术位
"hp:5"                   → 消耗5点生命值
"hit_dice:1"             → 消耗1个生命骰
"action:1"               → 消耗1个动作
"bonus_action:1"         → 消耗1个附赠动作
"reaction:1"             → 消耗1个反应
```

### 可用次数格式 (uses)

```
格式：数值或公式

示例：
"2"                      → 固定2次
"Proficiency"            → 熟练加值次数
"lv:class(1)"            → 野蛮人等级次数
"1"                      → 1次
"Character(不屈)"         → 角色"不屈"资源计数
```

## 使用条件格式 (prerequisites)

描述执行此动作的前提条件：

```
格式：条件1;条件2;条件3（分号分隔多个条件）

示例：
"not_wearing_heavy_armor"           → 未着装重甲
"has_shield"                        → 持用盾牌
"weapon_equipped:melee"             → 装备近战武器
"hp_below:0.5"                      → 生命值低于 50%
"condition:rage"                    → 处于狂暴状态
"not_condition:prone"               → 未处于倒地状态
"spell_slot_available:1"            → 有可用的一环法术位
"target_within:5"                   → 目标在 5 尺内
"ally_within:10"                    → 盟友在 10 尺内
"not_condition:incapacitated"       → 未失能
"weapon_equipped:ranged"            → 装备远程武器
"two_handed"                        → 双手持握武器
```

## 效果数据格式 (effect_data)

机器可读的效果描述，供战斗模块自动执行：

```json
{
  "type": "apply_condition",
  "condition_id": 100,
  "duration": {"type": "round", "value": 10},
  "target": "self"
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| type | string | 是 | 效果类型，见上方枚举 |
| condition_id | int | 否 | 状态效果表 ID（type=apply_condition 时必填） |
| damage_type | string | 否 | 伤害类型（type=deal_damage 时） |
| dice | string | 否 | 伤害骰（如 "1d8"） |
| target | string | 否 | 目标：self/ally/enemy/all_in_area |
| duration | object | 否 | 持续时间 {type, value} |
| range | int | 否 | 影响范围（英尺） |
| save_type | int | 否 | 豁免类型 |
| save_success | string | 否 | 豁免成功效果 |

## 常见错误

| 错误 | 正确 | 说明 |
|---|---|---|
| 动作类型写 "附赠动作" | 写 "bonus_action" | 用英文枚举值 |
| 消耗资源写 "1次狂暴" | 写 "rage_charge:1" | 用标准格式 |
| effect_data 写文本 | 写 JSON | 必须是机器可解析的 |
| 使用条件写 "要穿轻甲" | 写 "not_wearing_heavy_armor" | 用标准条件表达式 |
| 恢复条件写 "短休" | 写 "short_rest" | 用标准枚举值 |

## 与战斗模块的交互

战斗模块每回合构建可用动作列表的流程：

1. 读取角色职业/种族/专长 → 收集所有 source_type 匹配的动作
2. 检查每个动作的 `prerequisites` → 过滤掉不满足条件的
3. 检查 `uses` 和 `recharge` → 过滤掉次数用完的
4. 检查状态效果限制 → 某些状态可能禁用特定动作类型
5. 显示可用动作菜单给玩家/AI
6. 玩家/AI 选择动作后，解析 `effect_data` 执行效果
7. 如有 `ongoing_effect`，给目标施加对应状态
