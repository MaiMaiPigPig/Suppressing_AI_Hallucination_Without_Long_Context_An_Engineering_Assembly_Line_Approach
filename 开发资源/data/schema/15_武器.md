# 15_武器表 (weapons)

## 用途

描述角色可使用的武器。供以下模块使用：
- **车卡模块**：选择武器熟练项，装备武器时决定攻击骰和伤害骰
- **战斗模块**：武器类别决定熟练加值、伤害类型、精通效果
- **AI DM**：判断角色是否熟练使用当前武器

## 依赖

| 表名 | 用途 |
|---|---|
| 字典表 | `damage_type`、`properties`、`mastery`、`weapon_category`、`weapon_range` 引用值 |

## 版本状态

| 字段 | 状态 | 说明 |
|---|---|---|
| 全部字段 | ✅ v0.1 | 车卡/战斗功能已完整使用 |

## 表结构

| 列名 | 英文名 | 类型 | 必填 | 状态 | 默认值 | 说明 | 示例 | 常见错误 |
|---|---|---|---|---|---|---|---|---|
| id | id | int | 是 | ✅ | - | 唯一标识 | 1 | - |
| 名字 | name | string | 是 | ✅ | - | 中文武器名 | 短棒 | - |
| 英文名 | name_en | string | 否 | ✅ | - | 英文武器名 | Club | - |
| 伤害骰 | damage_dice | string | 是 | ✅ | - | 伤害骰表达式 | 1d4 | 写 1d4+2 或文字 |
| 伤害类型 | damage_type | string | 是 | ✅ | - | 英文伤害类型 | bludgeoning | 写"钝击" |
| 词条 | properties | int | 是 | ✅ | - | 武器词条（轻、灵巧、投掷等）ID，逗号分隔 | 1,4 | 写词条名而不是 ID |
| 精通 | mastery | int | 否 | ✅ | - | 武器精通属性 ID | 16（异怪） | 没精通写 0 |
| 重量 | weight | int | 否 | ✅ | - | 重量（磅） | 2 | - |
| 重量单位 | weight_unit | string | 否 | ✅ | lb | 重量单位 | lb | - |
| 价格 | cost | string | 否 | ✅ | - | 购买价格 | 1 SP | 格式：数字+空格+货币代码 |
| 简易/军用 | weapon_category | int | 是 | ✅ | - | 63=简易, 64=军用 | 63 | 写"简易" |
| 近战/远程 | weapon_range | int | 是 | ✅ | - | 61=近战, 62=远程 | 61 | 写"近战" |
| DLC | dlc | string | 是 | ✅ | phb | 所属 DLC 标识 | phb | - |

## 枚举值列表

| 值 | 含义 |
|---|---|

| piercing | 穿刺 |

| 值 | 含义 | 说明 |
