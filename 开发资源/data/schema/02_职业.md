# 02_职业表 (classes)

## 用途

描述可选的玩家职业。供以下模块使用：
- **车卡模块**：创建角色时选择职业，决定生命骰、熟练项、主属性
- **战斗模块**：生命骰影响升级 HP，主属性影响检定加值
- **AI DM**：根据职业背景生成角色叙事

## 依赖

| 表名 | 用途 |
|---|---|
| 职业特性表 | `feature_levels` 字段按等级引用职业特性，展开升级时获得的特性 |
| 施法表 | `spellcaster`=1 时，关联 `spellcasting` 等表获取法术位信息 |

## 表结构

| 列名 | 英文名 | 类型 | 必填 | 状态 | 默认值 | 说明 | 示例 | 常见错误 |
|---|---|---|---|---|---|---|---|---|
| id | id | int | 是 | ✅ | - | 唯一标识 | 1 | 与其他表 ID 冲突 |
| 名字 | name | string | 是 | ✅ | - | 中文职业名 | 野蛮人 | - |
| 英文名 | name_en | string | 否 | ✅ | - | 职业英文名，代码引用用 | barbarian | - |
| 生命骰 | hit_dice | string | 是 | ✅ | - | 每级生命骰（D6/D8/D10/D12） | D12 | 写"12"而不是 D12 |
| 主属性建议 | primary_ability | string | 是 | ✅ | - | 推荐主属性的字典 ID（可用竖线分隔多选） | 1\|4 | 直接写属性名 |
| 豁免熟练 | saving_throw_prof | string | 是 | ✅ | - | 初始豁免熟练项 ID，竖线分隔 | 1\|4 | - |
| 技能熟练项 | skill_prof | string | 是 | ✅ | - | 技能熟练选择规则（自描述表达式） | choose(skills(1,2,3,4,5,8))+2 | - |
| 武器熟练 | weapon | string | 是 | ✅ | - | 武器熟练规则（自描述表达式） | all(simple)+all(martial) | - |
| 工匠熟练 | tool | string | 是 | ✅ | - | 工具熟练规则（自描述表达式） | choose(tools(type=66),tools(type=67))+1 | - |
| 护甲类型 | armor | string | 是 | ✅ | - | 护甲熟练规则（自描述表达式） | all(light)+all(medium)+all(shield) | - |
| 是否施法者 | spellcaster | int | 是 | ✅ | 0 | 0=非施法者，1=施法者 | 0 | - |
| 初始专长 | feat | string | 否 | ✅ | - | 自描述表达式引用初始专长 | feats(type=42) | - |
| 专长等级 | feat_level | string | 否 | ✅ | - | 获得专长的等级列表 | 4,8,12,16,19 | - |
| 主职特性 | feature_levels | string | 是 | ✅ | - | 按等级列出职业特性 ID，格式："1=1,2,3;2=4,5;3=6" | 1=1;2=2,3 | 格式不对导致特性不显示 |
| 子职ID | subclass_id | string | 否 | ✅ | - | 关联的子职 ID 列表 | 1,2,3,4 | - |
| 子职等级 | subclass_level | int | 否 | ✅ | - | 获得子职的等级 | 3 | - |
| 喜好 | preference | string | 否 | ✅ | - | AI 自动分配时的偏好权重 | - | - |
| 魔力值 | cost | string | 否 | ✅ | - | 制作/学习的成本 | - | - |
| 推荐属性 | recommended_abilities | string | 否 | ✅ | - | 推荐分配的最高属性 | 1,4,18 | - |
| 升级生命值 | hp_per_level | int | 否 | ✅ | - | 升级时的固定 HP 增长（留空则掷生命骰） | 7 | - |
| DLC | dlc | string | 是 | ✅ | phb | 所属 DLC 标识 | phb | - |
| 详情 | detail | string | 否 | ✅ | - | 职业完整描述文本 | - | - |

## 枚举值列表

|---|---|---|
| D6 | d6 生命骰 | 法师、术士 |

| 值 | 含义 |
|---|---|
| 0 | 非施法者（无施法能力） |
| 1 | 施法者（有法术位） |
