# 01_种族表 (races)

## 用途

描述可选的玩家角色种族。供以下模块使用：
- **车卡模块**：创建角色时选择种族，应用种族属性加成和特性
- **战斗模块**：种族体型影响网格占用和移动规则
- **AI DM**：根据种族背景生成角色叙事

## 依赖

| 表名 | 用途 |
|---|---|
| 种族特性表 | `chain` 字段引用种族特性 ID，展开种族的能力列表 |
| 字典表 | `species`（物种类型）、`size`（体型）等引用字典值 |

## 版本状态

| 字段 | 状态 | 说明 |
|---|---|---|
| 基础字段（id~name） | ✅ v0.1 | 车卡功能已使用 |

## 表结构

| 列名 | 英文名 | 类型 | 必填 | 状态 | 默认值 | 说明 | 示例 | 常见错误 |
|---|---|---|---|---|---|---|---|---|
| id | id | int | 是 | ✅ | - | 唯一标识 | 1 | 与字典表 ID 冲突 |
| 名字 | name | string | 是 | ✅ | - | 中文种族名 | 阿斯莫 | - |
| 从属 | subrace | int | 否 | ✅ | 0 | 0=无子种族，>0=子种族 ID | 0 | 引用了不存在的子种族 ID |
| 等级 | level | int | 否 | ✅ | 1 | 种族生效等级 | 1 | - |
| 物种 | species | int | 是 | ✅ | - | 引用字典表-生物类型 | 25（类人） | 写"类人"而不是 25 |
| 体型 | size | string | 是 | ✅ | - | 引用字典表-体型（23/27/34/37/45/57/67/78） | 27 | 写"中型"而不是 27 |
| 速度 | speed | int | 是 | ✅ | - | 基础移动速度（英尺） | 30 | 写"30尺"而不是 30 |
| 特性chain: | chain | string | 是 | ✅ | - | 种族特性 ID 列表，英文逗号分隔 | 1,2,3,4,5,6 | 用中文顿号分隔 |
| DLC | dlc | string | 是 | ✅ | phb | 所属 DLC 标识 | phb | - |
| 详情 | desc | string | 是 | ✅ | - | 种族完整描述文本 | - | - |
