# 12_背景表 (backgrounds)

## 用途

描述角色可选的背景。供以下模块使用：
- **车卡模块**：创建角色时选择背景，获得属性加成、技能熟练、工具熟练和初始专长
- **AI DM**：生成角色背景故事

## 依赖

| 表名 | 用途 |
|---|---|
| 技能表 | 引用的技能 ID 必须存在 |
| 工具表 | 引用的工具 ID 必须存在 |
| 专长表 | `feat`（初始专长）ID 引用 |
| 字典表 | `attr`（属性加成）属性 ID |

| 字段 | 状态 | 说明 |
|---|---|---|
| 基础字段 | ✅ v0.1 | 车卡功能已使用 |
| 熟练项（skills/tool） | ✅ v0.1 | 选中背景后自动应用 |

## 表结构

| 列名 | 英文名 | 类型 | 必填 | 状态 | 默认值 | 说明 | 示例 | 常见错误 |
|---|---|---|---|---|---|---|---|---|
| id | id | int | 是 | ✅ | - | 唯一标识 | 1 | - |
| 名字 | name | string | 是 | ✅ | - | 中文背景名 | 侍僧 | - |
| 属性 | attr | string | 是 | ✅ | - | 属性加成配置（3组两位数的属性ID） | 1,11,18,25 | 格式不对 |
| 初始专长 | feat | int | 否 | ✅ | - | 起源专长 ID（引用专长表 type=42） | 5 | 引用了非起源专长 |
| 技能 | skills | string | 是 | ✅ | - | 技能熟练 ID，英文逗号分隔 | 2,11,17 | 中文顿号 |
| 工匠熟练 | tool | string | 否 | ✅ | - | 自描述表达式引用工具熟练 | tools(id=3) | - |
| 套装id | suit_id | string | 否 | ✅ | - | 关联起始装备套装 ID | 1,4,4 | - |
| DLC | dlc | string | 是 | ✅ | phb | 所属 DLC 标识 | phb | - |
| 详情 | desc | string | 是 | ✅ | - | 背景完整描述文本 | - | - |

## 枚举值列表

### 属性加成解析规则 (attr)

`attr` 字段为 3 组 2 位数拼接而成的字符串，每组表示一个属性加成目标：

```
格式：AABBCC
- AA, BB, CC：各为 2 位属性 ID
- 背景提供 +2 给其中一个，+1 给另外两个

示例：111825
→ 属性 ID=11（智力）+2，属性 ID=18（感知）+1，属性 ID=25（魅力）+1

示例：4918
→ 属性 ID=4（敏捷）+2，属性 ID=9（体质）+1，属性 ID=18（感知）+1
```

### 属性 ID 对照

| 属性 ID | 属性名 | 英文 |
|---|---|---|
| 1 | 力量 | Strength |
| 4 | 敏捷 | Dexterity |
| 9 | 体质 | Constitution |
| 11 | 智力 | Intelligence |
| 18 | 感知 | Wisdom |
| 25 | 魅力 | Charisma |

### 初始专长 (feat)

引用专长表中 `type=42`（起源专长）的条目。常见值：

| 值 | 专长名 |
|---|---|
| 1 | 警戒 |
| 5 | 音乐家 |
| ... | 其他 origin feats |
